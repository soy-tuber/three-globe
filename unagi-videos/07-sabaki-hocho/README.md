# 07 鰻を捌くとき、包丁の中で何が起きているか

`index.html` 1ファイルだけで動く、インタラクティブな3D解説ページです。依頼文は `.claude/skills/threejs-explainer-sns-video/examples/unagi/07-sabaki-hocho.md`、事実確認は同じ場所の `FACT-CHECK.md` にあります。

- three.js 0.183.2 を jsDelivr から importmap で読み込みます。フォントは Google Fonts のみで、ほかの外部通信はありません。
- 形はすべてコードで作り、模様は CanvasTexture とシェーダーで描いています（外部の3Dモデルと画像は使っていません）。鰻の体は半透明の模式図で、血や内臓は描いていません（内臓は分解表示で「位置」だけを淡い形で示します）。
- 動画：`video/07-sabaki-hocho.mp4`（1920×1080・30fps・30秒、効果音入り）、確認用の一覧：`video/check-frames.png`

## 模型の中身（値はすべて原理を示すための模型の値）

- 刃先の圧力：p = F / A、A = 刃先の幅 0.04mm × 当たる長さ 1.5cm。押す力 18N で約30MPa。同じ力でも刃先の幅が0.4mmなら3MPa、1mmなら1.2MPaになります（拡大図の曲線）。身が切れる限界は2MPa、背骨の限界は80MPa（模型の値）なので、刃は身を切り、背骨は切れません。
- 刃の道：刃の角度 Δθ は、背骨の面に対する刃の傾き。刃が x 進むと、背骨からの距離は x × tanΔθ だけ変わります。骨に残る身の量は、この距離（最大1.2cm）を切る長さ48cmにわたって積分し、密度1.05g/cm³と高さ1cmを掛けたものです。
- 背骨に向かう側：±0.6°の中では、刃は背骨に沿って進みます。それより深く向けると、刃は浅い角度で背骨に当たり、切れずに滑ります（滑る向きを赤い軌跡で示します）。その先は切れずに残ります。
- きれいに開ける範囲：±0.6°（残る身が約14g以下）。角度が0.6°から1°、2°とずれるだけで、残る身は約14g、23g、40gと急に増えます。
- 工程の時間（模型の値）：②入れる0.06秒、③沿わせる0.42秒、④開く0.14秒。この区間を約10倍のスローで見せ、経過を実時間で表示します。⑤外す、⑥整えるはその後に続けて見せます。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setAngle(度)` | 刃の角度（背骨の面に対する傾き、−6〜+6）を設定し、状態を同期で返す（刃先の圧力・骨に残る身の量・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | お手本（新しい鰻で、刃を背骨の面に合わせて保つ） |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `edge` / `section` / `craftsman`） |
| `setSpeed('slow'｜'real')` | スロー表示（約10倍）と実時間の切り替え |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `predictLeftover(度)`, `pressure(N, mm)`, `perf()` | 角度ごとの残る身の量（g）、力と刃先の幅ごとの圧力（MPa）、描画コストと画素比 |

## 依頼文から変えたところ

- 失敗のあと「数秒後に角度を戻すと元に戻る」は、失敗から2秒以上たち、角度がきれいに開ける範囲に戻ったときに、新しい鰻の状態に戻す形にしました。捌き終えたあとに角度を範囲の外へ動かすと、次の鰻に替わります。
- 工程①〜⑥のうち、スロー表示と実時間のカウンタは②〜④（刃を入れてから開くまで）に当てました。捌き全体の所要時間は出典で確認できないため、画面に出していません。
- 事実確認に合わせて、完了時の文言を「生きた鰻を捌くのは難しく、熟練を要する仕事です」、18.5〜23秒と27〜30秒の字幕を依頼文の改訂版どおり、工程⑥を「整える　ヒレを落とす」にしています。
- 押さえる手には、分解表示の「切創防止の手袋」と同じ手袋を着けています（出典④で保護手袋の使用が対策に挙げられているため）。
