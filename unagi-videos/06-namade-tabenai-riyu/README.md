## 模型の中身（60℃・5分のほかは、原理を示すための模型の値）

- 毒として働く割合 F：1次反応 dF/dt = −k(T)·F。1刻みごとに F ← F·exp(−k·Δt) で厳密に進めるので、温度と時間の履歴をそのまま積分した値になります。
- 速さ k(T)：アレニウスの式 k = A·exp(−Ea/RT)。Ea = 300 kJ/mol（模型の値）、A は k(60℃) = 0.02/秒 になるように決めています。60℃ に5分保つと F = e⁻⁶ ≈ 0.25% になり、表示はここで 0%（加熱済み）になります。
- 「形がほどけ始める温度」の破線：k が 0.001/秒 を越える温度（約51.0℃、模型の値）。60℃ は当てはめていません。低い温度では、時間をかけてもほとんど下がりません（例：45℃ では半分になるまで約95分）。
- たんぱく質の模式図：40粒の鎖を10本。折りたたみは小さな球の中に収めた鎖で、空間的に近い粒どうしを「結びつき」の線で結びます。ほどけると、端から順にひものように伸びます。割合 F が各鎖の順位を下回ったものからほどけるので、折りたたまれた鎖の割合が F に合います。揺れの大きさは温度とともに大きくなり、ほどけ始めた瞬間に白く光ります。
- 飛ぶ血のしずくの軌跡：軸が鉛直な放物線（一様にたどる2次ベジェ曲線は加速度が一定なので、放物運動の模式表示になります）。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setTemperature(℃)` | 加熱の温度を設定し、状態を同期で返す（速さ・毒として働く割合・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | 加熱（生の状態から 60℃ まで上げ、割合が 0% になるまで保つ） |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `blood` / `protein` / `bench`） |
| `setSpeed('slow'｜'real')` | 早回し表示（約52倍）と実時間の切り替え（`slow` は早回し） |
| `setSplash(on)` | 生の血が飛ぶ場面の切り替え。`setGoggles(on)` は互換のため残し、`setSplash(!on)` と同じ動き |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `rateK(℃)`, `perf()` | 温度ごとの速さ（/秒）、描画コストと画素比 |

## 依頼文から変えたところ

- 加熱は数分かかるので、「約30倍のスロー」ではなく「早回し表示（約52倍）」にしました（しきい値を越えてから完了までが14〜18.5秒の区間に収まる倍率）。完了時に「60℃、5分の加熱で、完全に毒性を失います」を出し、実時間にも切り替えられます。
- 表示の 0% は、この模型で 60℃ に5分保ったときに残る割合（e⁻⁶ ≈ 0.25%）以下としました。60℃ にすぐ上げた場合、経過はちょうど5分00秒で完了します。デモでは温度を上げていく時間も含むので、経過は5分を少し越えます。
- 失敗の場面の人物は、実在の人や製品に似せない半透明の模式的な人形にし、保護具は描いていません（保護メガネや手袋の着用は画面で指示しない、という依頼に合わせています）。警告の文は厚生労働省の原文どおりで、対処法は書いていません。
