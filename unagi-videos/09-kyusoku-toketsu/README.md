# 09 急速凍結すると、なぜ解凍してもおいしいのか

`index.html` 1ファイルだけで動く、インタラクティブな3D解説ページです。依頼文は `.claude/skills/threejs-explainer-sns-video/examples/unagi/09-kyusoku-toketsu.md`、事実確認は同じ場所の `FACT-CHECK.md` にあります。

- three.js 0.183.2 を jsDelivr から importmap で読み込みます。フォントは Google Fonts のみで、ほかの外部通信はありません。
- 形はすべてコードで作り、模様は CanvasTexture とシェーダーで描いています（外部の3Dモデルと画像は使っていません）。
- 動画：`video/09-kyusoku-toketsu.mp4`（1920×1080・30fps・30秒、効果音入り）、確認用の一覧：`video/check-frames.png`

## 模型の中身（値は原理を示すための模型の値）

- 蒲焼き（18×8×1.5cm、真空包装を含めて1枚の板）の厚さ方向を19点に分け、凍るときの潜熱を含むエンタルピー法で1次元の熱伝導を解きます（陽解法、刻み0.4秒）。水分60%、凍り始める温度 −1℃。凍り始める温度より下では、水のうち凍った割合を 1 − (−1℃)/T としています。−5℃ で約8割が凍るので、そこまで潜熱が出続け、温度の下がり方が鈍ります。
- 表面の条件：冷気の温度と、風の強さで決まる熱伝達率（両面）。冷やす速さの目盛り1つで、庫内 −20〜−40℃ と 6〜66 W/m²K を同時に動かします。
- 結晶が育ちやすい温度帯（−1〜−5℃）に各層がとどまった時間 t から、結晶の大きさ（細胞との比）を 0.15 + 1.65(1 − e^(−t/2488秒)) で決めます。中心が30分でちょうど細胞と同じ大きさ（1.0倍）になるように合わせ、上限は1.8倍で頭打ちにしています。
- 「結晶が小さいまま凍るライン」は、中心が温度帯を通り抜ける時間30分です（もっと知る②の認定基準「概ね30分以内」に合わせた模型の値）。この模型では目盛りの約53%で30分を下回ります。
- ドリップ：各層の結晶が細胞より大きくなった度合い（0.95〜1.6倍の間をなめらかにつなぐ）の平均から、解凍したときに流れ出す量を求めます（0.2〜8.2%、画面では「わずか／やや多い／多い」と表示）。
- 通り抜ける時間の予測（メーターとグラフの破線）：目盛りを41段階に分けて、同じ模型をあらかじめ計算した表から補間しています。凍結が始まってからは、実際に計算した値を表示します。
- 保存と解凍は模式表示です（時間の経過は数えません）。解凍では、結晶が溶けて、傷んだ細胞からは水分が流れ出します。

## フック

`window.__lab` から操作できます。

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setCoolingRate(0〜1)` | 冷やす速さの目盛りを設定し、状態を同期で返す（通り抜ける時間・結晶の大きさ・ドリップの量の予測と、成功・失敗の判定まで反映済み。ラインを越えるとその場で凍結が始まる） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | 急速凍結（新しい製品で、目盛りをラインの上まで上げる） |
| `slowFreeze()` | 緩慢凍結（新しい製品を、目盛りを下げた状態で凍らせる） |
| `thaw()` | 冷凍保存中なら、すぐに解凍する |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `inside` / `cells` / `plate`） |
| `setSpeed('fast'｜'real')` | 早回し表示と実時間の切り替え |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `predict(u)`, `perf()` | 目盛りごとの予測（通り抜ける時間・結晶・ドリップ）、描画コストと画素比 |

## 依頼文から変えたところ

- 早回しの倍率：凍結は数十分から数時間かかるので、「約300倍」ではなく、急速凍結は「早回し表示（約600倍）」、緩慢凍結は「早回し表示（約6,000倍）」にしました。しきい値から完了までが14〜18.5秒、ゆっくり凍らせる場面が23〜27秒に収まる倍率で、画面の表示も倍率に合わせて切り替わります。保存と解凍は、時間を数えない模式表示にしました。
- 最初の2秒で身の中の結晶が見えるように、初期状態は「表面がちょうど凍り始めたところ」（表面 −1.3℃、中心 1.5℃）にしました。
- 身の拡大図は、製品が皿へ移ると皿の上へ付いていき、解凍後の細胞と皿のドリップを同じ画面で見せます。
- 事実確認に合わせて、「最大氷結晶生成温度帯」「小さいまま」の言い方、完了時の文言（数値なし）、メーターのライン名、グラフの注記を原文どおりにしています（`FACT-CHECK.md`）。
