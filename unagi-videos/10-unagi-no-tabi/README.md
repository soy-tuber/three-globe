# 10 鰻はどこから来るのか（海を渡る長い旅）

`index.html` 1ファイルだけで動く、インタラクティブな3D解説ページです。依頼文は `.claude/skills/threejs-explainer-sns-video/examples/unagi/10-unagi-no-tabi.md`、事実確認は同じ場所の `FACT-CHECK.md` にあります。

- three.js 0.183.2 を jsDelivr から importmap で読み込みます。フォントは Google Fonts のみで、ほかの外部通信はありません。
- 形はすべてコードで作り、模様は CanvasTexture とシェーダーで描いています（外部の3Dモデルと画像は使っていません）。
- 地球儀の陸地は、簡略化した海岸線の座標の配列をコードに持ち、CanvasTexture に描いています。地図の画像やタイルは読み込みません。
  - 元のデータは Natural Earth（パブリックドメイン）です。地球全体は 1:110m の陸地、西太平洋（東経98〜167度、南緯8度〜北緯52度）は 1:50m の陸地を切り抜いて使っています。作成時に Douglas–Peucker 法で簡略化し、経度・緯度の数値だけを埋め込んでいます。
- 動画：`video/10-unagi-no-tabi.mp4`（1920×1080・30fps・30秒、効果音入り）、確認用の一覧：`video/check-frames.png`

## 開き方

```sh
cd unagi-videos/10-unagi-no-tabi && python3 -m http.server 8000
# http://localhost:8000/        通常の操作（地球儀の下の時間の輪をドラッグ、ホイール、↑↓キー、スライダー。それ以外のドラッグで地球儀を回す）
# http://localhost:8000/?demo=1 30秒の自動再生（録画用）
```

## 模型の中身（原理は資料の説明どおり、強さ・距離・日数は模型の値）

- 地球儀：半径100の球。緯度経度から3次元の座標に変換します。陸地はぼかした陸地のマスクとして CanvasTexture に描き、シェーダーで 0.5 のしきい値を取って海岸線を描くので、寄っても輪郭がにじみません。夜明けの光は、太陽の方向との内積で昼と夜を分けています。
- 海流：緯度経度の上の滑らかな速度場（0.25度の格子に表にして双一次補間）。
  - 北赤道海流：北緯約14度を中心に西向き（0.22 m/秒）。
  - フィリピン沖の分かれ目：北緯14.2度より北は北へ、南は南へ向かいます。
  - 黒潮：中心線に沿ったガウス分布の流れ（最大 1.2 m/秒）。その東側の水を引き込みます。
  - 南へ向かう海流：ミンダナオ沖を南へ流れます。
  - 日本の南岸近くには、ごく弱い岸向きの流れを入れています。
- 子どもたち：900粒。産卵場（北緯14.6度・東経142度付近）から出発し、海流の速度場とランダムウォーク（乱数の種は固定、拡散係数 400 m²/秒）の和の中を RK4 で追跡します。半日刻みで8か月分を起動時に計算して表にしているので、どの月数の状態も同期で返せます。粒は陸地を通れません。
- 大陸棚の縁：日本の南岸沖に置いた模型の等深線です。ここから0.12度以内に来た粒を「たどり着いた」として、その日数を記録します。
  - 最初の粒は約3.7か月でたどり着きます（時間の輪の中ほど）。
  - 8か月で約42%がたどり着き、約36%はフィリピン沖で南へ運ばれ、約21%は日本の沖を通り過ぎます（いずれも模型の値）。
- 一生の早回し：最初の粒がたどり着いた瞬間に、その子がシラスウナギに変わったとみなします（白い閃光）。そこから、川や河口にのぼって10年で銀ウナギになるまで（資料の「5年から15年」の範囲の模型の値）を早回しで見せます。帰り道は分かっていないので、薄い点の列の模式図にしています。
- 分解の倍率：全長は、水産庁の資料（レプトセファルス 12〜60mm、シラスウナギ 50〜60mm、クロコ 約50〜80mm、黄ウナギ 約80mm〜30cm、銀ウナギ 約45cm〜）と、水産庁・水産研究・教育機構の資料（卵の直径 約1.6mm）によります。
  - 黄ウナギ（30cm）と銀ウナギ（50cm）を等倍とし、そのほかは拡大して描いています。卵は100倍、レプトセファルス（60mm）とシラスウナギ（55mm）は4倍、クロコ（70mm）は3倍です。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setMonth(月数)` | 生まれてからの月数（0〜8）を設定し、状態を同期で返す（粒の位置・たどり着いた割合・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期）。`firstChild` は先頭の子の位置、`drifting` / `carriedSouth` / `carriedPastJapan` は粒の数 |
| `tap()` | 旅を再生（月数を0に戻して自動で進める） |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `spawn` / `kuroshio` / `river`） |
| `setSpeed('fast'｜'real')` | 早回しと実時間の切り替え |
| `followLost(on)` | 海流から外れた粒を追う（フィリピン沖で南へ運ばれる軌跡） |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `currentAt(lat, lon)`, `perf()` | 場所ごとの海流（模型の値）、描画コストと画素比 |

## 依頼文から変えたところ

- 早回しの倍率：旅は月の単位、一生は年の単位なので、「約1万倍」の1つの倍率では30秒に収まりません。
  - 旅は時間の輪の月数で進めます。
  - たどり着いたあとの一生は、「1秒で約1か月」から「1秒で約2.5年」まで上げていく早回しで見せ、表示も今の速さに合わせて出します。
- 成功の「コーン」は、一生の早回しが終わって銀ウナギになる時点（18.5〜23秒の区間）で鳴らします。吹き出しは依頼どおり「日本の沿岸にたどり着きました　海流に乗って数千kmの旅」です。シラスウナギに変わる瞬間（しきい値）は白い閃光で見せます。
- 「日本の沿岸に届き始めるライン」の破線は、月数のメーターの上（最初の粒が届く月数）に置きました。たどり着いた割合のメーターは、線形の 0〜100% のままです。
- 海岸線：リポジトリにある Natural Earth 1:110m の国境データには四国がないため、西太平洋は同じ Natural Earth の 1:50m の陸地を使いました。
- 失敗の吹き出しの小さな文字「黒潮に乗れず、フィリピン沖で南へ向かう海流に運ばれていきます（模式図）」は、もっと知る②の内容を短くしたものです。
- ④のレッドリストの区分は、汽水・淡水魚類の第5次レッドリストが公表されると変わる可能性があるので、公開の直前にもう一度確認してください。
