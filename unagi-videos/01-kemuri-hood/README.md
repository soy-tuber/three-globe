## 模型の中身（値は原理を示すための模型の値）

- 煙の上昇：焼き台（90×40cm）の上の上昇気流。中心の上昇速度は約0.42m/sで、高さとともに遅くなり、ガウス分布の幅が広がります。
- フードの吸い込み：フランジ付きの外付け式フードの Dalla Valle の式 V = Q / (0.75 × (10x² + A))（x は口の中心からの距離 m、A は口の面積 1.2×0.6 m²）。口の面より上（フードの外側）からは吸いません。
- 捕集率：フードの縁の96点で、縁のすぐ外の吸い込みの速さと煙の上昇速度を比べ、煙の量で重みを付けた割合です。風量の目盛りの約0.57で95%（「煙がすべて収まる最低ライン」）を越えます。
- 煙の粒：1,800粒を、上昇気流と吸い込みの和の流れの中で RK4 で追跡します。口の手前に来た粒は、そのときの捕集率に応じて「フードに入る／縁からあふれる」に分かれ、あふれた粒は天井沿いに客席側へ流れます。
- 給気口を閉じたとき：ファンの特性 Q(1 − ΔP/60Pa) とすき間からの流入 C√ΔP の釣り合いで店内の気圧が下がり、実際に吸える量が減ります。扉にかかる力は気圧差×扉の面積（模式表示）。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setAirflow(0〜1)` | 風量の目盛りを設定し、状態を同期で返す（捕集率と成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | 自動調整（しきい値の少し上まで風量をなめらかに上げる） |
| `setMakeupAir(open)` | 給気口の開閉 |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `grill` / `hoodIn` / `seats`） |
| `setSpeed('slow'｜'real')` | 煙の粒を追うスロー（約3.5倍）と実時間の切り替え |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `captureRatio(dial)`, `perf()` | 目盛りごとの捕集率、描画コストと画素比 |

## 依頼文から変えたところ

- 煙の粒の旅は模型の実時間で約1.9秒なので、「約20倍のスロー」ではなく、14〜18.5秒の区間に収まる「スロー表示（約3.5倍）」にしました。
- 事実確認に合わせて、吸い込みの式をフランジ付きの形に、「実際には約2秒」を「この模型では約2秒」に直し、給気口を閉じたときの動きが模式表示である旨を注記に加えました。扉の「開けにくい」は公的資料で確認できなかったため、模型の気圧差から計算した力として表示し、すき間から入る「隙間風」もあわせて見せています。
