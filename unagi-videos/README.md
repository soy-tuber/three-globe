# 鰻の解説ページと SNS 用動画（10本）

鰻の飲食業・加工業の採用と教育に使う、インタラクティブな3D解説ページと、SNS に投稿する30秒の動画です。
依頼文は `.claude/skills/threejs-explainer-sns-video/examples/unagi/`、事実確認の記録は同じ場所の `FACT-CHECK.md` にあります。作り方は同じスキルの `SKILL.md` に沿っています。

## 開き方

モジュールを使うので、ローカルサーバーから開いてください（`file://` では動きません）。

```sh
cd unagi-videos && python3 -m http.server 8000
# http://localhost:8000/04-binchotan-yaki/          通常の操作
# http://localhost:8000/04-binchotan-yaki/?demo=1   30秒の自動再生（録画用）
```

## 共通の作り

- **ファイルと通信**
  - 1ページ1ファイルの `index.html` です。
  - three.js 0.183.2 を jsDelivr から importmap で読み込みます。
  - フォントは Google Fonts だけで、ほかの外部通信はありません。
- **形と模様**
  - 形はすべてコードで作り、模様は CanvasTexture とシェーダーで描いています。外部の3Dモデルと画像は使っていません。
  - 10 の地球儀の陸地は、Natural Earth（パブリックドメイン）の海岸線を簡略化した座標の配列としてコードに持っています。地図の画像やタイルは読み込みません。
- **操作**
  - 主役の部品（温度計、つまみ、串、包丁の柄など）に触れたときだけ値が変わり、それ以外のドラッグはカメラを回します。
  - ホイール、↑↓キー、スライダーでも同じ値が動きます。
  - ボタンは、お手本（自動）、分解、早回し（またはスロー）と実時間の切り替え、失敗の場面、カメラです。
  - 「もっと知る」は出典のリンクつきの開閉パネルです。
- **スマホ幅（390px）**
  - 上に見出しとボタン、下のシートに値と工程と操作をまとめています。
  - グラフと記録は「開く」で出します。
- **文言**
  - 画面の文言はすべて日本語で、「！」と絵文字は使っていません。
  - 模型の値には「模型の値」、形には「模式図」と明記しています。

## 検査用のフック

`window.__lab` から操作できます。名前はページごとに違うので、細かいところは各ページの README を見てください。

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `set〇〇(値)` | 主役の値を設定し、状態を同期で返す（成功・失敗の判定まで反映済み）。例：`setHeight`（04）、`setTemperature`（06、08）、`setAngle`（07）、`setMonth`（10） |
| `getState()` | 現在の状態を同期で返す |
| `tap()` | お手本（しきい値の少し上まで自動で動かす） |
| `setExploded(on)`, `setCamera(name, instant)`, `setSpeed(mode)` | 分解表示、カメラ、早回し／スローと実時間の切り替え |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを、同期的かつ決定的に描画する（1/120秒刻みの再計算。成功や失敗の時刻を `events` として返す） |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `perf()` | 描画コストと画素比 |

## 動画の作り方

- **書き出し**
  - スキルの `scripts/export.cjs` で、`?demo=1` のページの `renderDemoFrame(t)` を1フレームずつ描き、1920×1080・30fps・30秒の H.264 にしました。
- **効果音**
  - 書き出しで返る `events` の実測の時刻に合わせ、`scripts/cues.py`（標準ライブラリだけで正弦波を重ねる）で作りました。音はチン、ブブー、コトン、ピピピ、ポン、スッ、ピッ、ピピピピピ、カチッ、コーンです。
  - ffmpeg で AAC 192kbps として重ねました。
  - 最大音量は、きっかけごとに volumedetect で確かめました（おおむね −7〜−14dB、効果音のない区間は −91dB）。
- **確認**
  - 完成した動画から代表の時刻のフレームを抜き出して `video/check-frames.png` にまとめ、字幕と絵が台本どおりかを確かめました。字幕は10本とも依頼文と一字一句同じです。
- **WSL2 で RTX 5090 を使う設定**
  - ヘッドレスの Chrome で GPU を使うには、次の環境変数を付けてシステムの Chrome を使います。

    ```sh
    GALLIUM_DRIVER=d3d12 LD_LIBRARY_PATH=/usr/lib/wsl/lib MESA_D3D12_DEFAULT_ADAPTER_NAME=NVIDIA CHROMIUM=/usr/bin/google-chrome
    ```

  - 付けないと、ソフトウェア描画（llvmpipe、約17fps）になります。

## 公開の前に確かめること

- **01**：清掃と点検の頻度は自治体ごとに違います。出店先が東京都以外なら、その自治体の条例と基準を確認してください。
- **06**：自社の安全ルールで保護メガネを定めている場合は、その根拠を示したうえで、画面の表示を戻すかを決めてください（鰻の血に対して保護具を勧める公的資料は見つからず、画面では指示していません）。
- **08**：画面の 10℃ は手引書の例です。店や工場の衛生管理計画（HACCP）の基準に合わせて直してください。失敗の見出し「置きっぱなし　すぐに冷蔵庫へ」は依頼文どおりで、下に政府広報オンラインの原文をそのまま添えています。
- **09**：0〜3秒の字幕「冷凍の蒲焼きは、凍らせ方で味が変わります」の出典は、食品一般と食肉についての資料です。小さな結晶が「細胞の中にも外にも」できる絵は、依頼文どおりの模式図です。
- **10**：ニホンウナギのレッドリストの区分は、汽水・淡水魚類の第5次レッドリストが公表されると変わる可能性があります。公開の直前に環境省のページで確認してください。
