## 模型の中身（値はすべて原理を示すための模型の値）

- 物質収支を1日ごとに進めます。1日に割合 f を新しいタレに入れ替えると、創業時のタレの割合は O(n) = (1 − f)^n です（片対数のグラフでは直線になります）。
- 濃さ（足すタレを 1 としたとき）：S(n+1) = (1 − f)·S(n)·E ＋ f·1 ＋ U。E = 1.01 は蒸発による濃縮、U = 0.02 は鰻から溶け出す分（模型の仮定）で、焼く本数の日ごとの違いとして ±40% の揺れを入れています。定常値は S* = (f + U) / (1 − (1 − f)E) です。
- 「味が落ち着く範囲」は S* ±5% です。入った時点をしきい値とし、目盛りの中ほど（f = 7%）では30日目に入ります。一度入ったあとは、日ごとの揺れで出入りしないよう、±8% を越えたときだけ外れたとみなします。
- 鰻の脂と旨味の粒（白、模型の仮定）の割合は、W(n+1) = (1 − f)·W(n) + u（u = 0.6%/日）で求めます。
- 継ぎ足しを止めると S(n+1) = S(n)·E ＋ U で濃さが上がり続け、2.2 を越えると「煮詰まりすぎ」です（2.5 で頭打ち）。量が減り、壺の内側と縁に焦げが付きます。継ぎ足す量が少なすぎても（f が約3.5%未満）、定常値が 2.2 を越えるので煮詰まります。
- 粒：720粒。壺の中の軸対称な対流の渦（流れ関数 ψ = r²(1 − r²)(1 − z²)²。中心で上がり、壁ぎわで下がる）を RK4 で追います。粒の色は、上の式の割合と一致するように決めています（創業時の粒は割合 O、残りのうち W/(1 − O) が白、ほかが明るい琥珀）。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setRefill(割合0〜1)` | 1日に継ぎ足す割合を設定し、状態を同期で返す（創業時の割合・濃さ・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | 1年を再生（創業の日から、1年たつまで日付を進める。しきい値を越えると、漬けて焼く1回を1度見せる） |
| `setDay(n)` | 創業の日から n 日目まで一気に進め、状態を同期で返す（漬けて焼く1回の場面は省く） |
| `setStop(on)` | 継ぎ足しを止める／戻す |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `tsubo` / `grill` / `kabayaki`） |
| `setSpeed('slow'｜'real')` | 漬けて焼く1回の早回し表示（約2.5倍）と実時間の切り替え（`slow` は早回し） |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `steady(f)`, `perf()` | 継ぎ足す割合ごとの定常の濃さ、描画コストと画素比 |

## 依頼文から変えたところ

- 漬けて焼く1回は、この模型では12秒（「十数秒」）です。14〜18.5秒の区間に収めるため、「約10倍のスロー」ではなく「早回し表示（約2.5倍）」にしました。日付のほうは早送りで進みます。
- 成功の表示の割合は模型の計算値です。目盛りの中ほど（f = 7%）で濃さが落ち着く30日目には 11% で、そのあと日付が1年まで進むと 0.01% 未満になります（表示は日付とともに変わります）。依頼時の例の 0.3% は使っていません。
- 事実確認に合わせて、鰻の脂と旨味は「模型の仮定」と明記し（凡例、①〜⑥の③、分解の層）、失敗の操作は「継ぎ足しを止める」にしました。
