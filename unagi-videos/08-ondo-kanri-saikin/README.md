## 模型の中身（10℃ は手引書の冷蔵の例。ほかは原理を示すための模型の値）

- 増える速さ：平方根モデル √r = b·(T − Tmin)。r は1時間あたりに倍になる回数、Tmin = −6℃（冷蔵庫の中より低く、−15℃ より高い位置に置いた模型の値）。b は 25℃ で倍になるまで20分になるように決めています。倍になるまでの時間は、3℃ で約3時間57分、10℃ で約1時間15分、25℃ で20分です。−6℃ 以下では増えません。
- 最初の「待つ」（誘導期）：N = N0 · (1 + q0·2^Θ) / (1 + q0)、Θ = ∫ r dt（温度の履歴をそのまま積分）、q0 = 0.5。誘導期は倍になるまでの時間の約1.6倍になり、その後は N0 · 2^(t/倍加時間) に沿って増えます。
- 数：最初は1,000個（模型の値）。100万個で頭打ちにし、「数えきれない」と表示します。メーターは対数の目盛りです。
- 画面の粒：最初の2回の倍（16粒 → 64粒）はそのまま増やし、その後は数の対数に比例して間引いた模式表示です。どの粒がいつ分かれるかは、種を固定した乱数で事前に決めてあり、分かれる間隔は計算した倍加時間に比例します。作業台の身の上の粒と、上に浮かぶ「身の表面（拡大）」の粒は、同じ増え方で動きます。
- 基準の温度：身の温度が 10℃（冷蔵の例）を越えると、身の縁と拡大した表面の縁が赤く光ります。
- 冷蔵庫の中は 3℃、置きっぱなしの室温は 25℃（どちらも模型の値）。作業台の温度計は作業台の温度を変えます。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setTemperature(℃)` | 作業台の温度を設定し、状態を同期で返す（身が作業台にあれば、倍加時間・数・基準を越えたか・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期） |
| `tap()` | 冷蔵庫へ（扉を開けて身を入れ、扉を閉めて温度を記録する） |
| `leaveOut(on)` | 置きっぱなし（冷蔵庫から出して作業台に置き、室温で置いておく）。`false` で冷蔵庫へ戻す |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `surface` / `fridge` / `record` ほか） |
| `setSpeed('fast'｜'real')` | 早回しと実時間の切り替え |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `growthRate(℃)`, `doublingTimeMin(℃)`, `perf()` | 温度ごとの増える速さ（倍/時）と倍になるまでの時間（分）、描画コストと画素比 |

## 依頼文から変えたところ

- 早回しは、しきい値を越えたあとだけでなく最初から「早回し表示（約1,000倍）」にしました。実時間では倍になるまで数時間かかり、③の「粒が分かれる間隔が短くなる」が見えないためです。「置きっぱなし」のボタンは数時間を数秒で見せるため約6,000倍、冷蔵庫への出し入れは実時間です（扉を開けたまま時計が早回しで進む絵にしないため）。
- 「拡大した部分」は、06 の血液のしずくと同じく、作業台の上に浮かぶ泡「身の表面（拡大）」として見せ、「身の表面」のカメラはその中に入ります。
- 成功の「ピッ」は、身を冷蔵庫に入れて扉が閉まった瞬間で、記録表に1行加わります。白い閃光は、身が冷蔵庫に入った瞬間（扉が閉まる約0.9秒前）に出します。
- しきい値の破線「基準の温度（冷蔵の例 10℃）を越えたライン」は、温度のメーターに付けました（しきい値が温度のため）。細菌の数のメーターは対数の目盛り（1000、1万、10万、100万）です。
- デモでは、置きっぱなしで数が振り切れたあと、27秒で分解表示に移ります（通常の操作では、失敗の3秒後に冷蔵庫へ戻します）。
- 成功の吹き出しの小さな文字は、政府広報オンラインの「冷蔵庫に入れても、細菌はゆっくりと増殖します」を用語の規則（「増える」）に合わせたものです。
- 失敗の吹き出しは、依頼文の「置きっぱなし　すぐに冷蔵庫へ」の下に、対処の根拠として政府広報オンラインの原文「肉や魚などの生鮮食品やお総菜などは、購入後、できるだけ早く冷蔵庫に入れましょう」をそのまま添えています（安全に関わる対処は公的な出典の原文どおりに示すため）。
