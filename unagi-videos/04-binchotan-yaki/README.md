# 04 炭火で焼くと、なぜ皮はパリッと中はふっくらするのか

`index.html` 1ファイルだけで動く、インタラクティブな3D解説ページです。依頼文は `.claude/skills/threejs-explainer-sns-video/examples/unagi/04-binchotan-yaki.md`、事実確認は同じ場所の `FACT-CHECK.md` にあります。

- three.js 0.183.2 を jsDelivr から importmap で読み込みます。フォントは Google Fonts のみで、ほかの外部通信はありません。
- 形はすべてコードで作り、模様は CanvasTexture とシェーダーで描いています（外部の3Dモデルと画像は使っていません）。
- 動画：`video/04-binchotan-yaki.mp4`（1920×1080・30fps・30秒、効果音入り）、確認用の一覧：`video/check-frames.png`

## 模型の中身（値は原理を示すための模型の値）

- 受ける熱の量：炭床（60×30cm）を一様な温度の面とみなし、q = εσT⁴ × 形態係数 F(h)。F(h) は平行な長方形どうしの厳密式（微小面→長方形の角の式を4つ重ねる）を、鰻の下面の 9×3 点で平均しています。
- 皮の表面温度：受ける熱 ＝ 対流 ＋ 再放射 ＋（皮と乾いた層を通って 100℃ の蒸発の前線へ流れる熱）の釣り合いから求めます。乾いた層が育つほど断熱されて表面が熱くなるので、焼き手は串を上げていきます。
- 身の中：厚さ方向 25 点の1次元熱伝導（陽解法）。水分が残る層は 100℃ で止まり、余った熱で乾いていきます。
- 焼き色は約150℃、焦げは約220℃を越えた時間の積分で判定します。
- 光の筋は、炭の表面から出る向きのそろった光線（余弦分布）1,500本のうち、鰻の下面に当たったものだけを明るく描いています。当たる本数の割合が形態係数に当たります。

## フック

`window.__lab` から操作できます。

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setHeight(cm)` | 串の高さ（炭の表面から）を設定し、状態を同期で返す（受ける熱・表面温度・焼き色・焦げの判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期）。`profile` は厚さ方向の温度分布 |
| `tap()` | お手本（新しい鰻を焼き色の高さまで下げ、乾いた層の育ち方に合わせて串を上げていく） |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `grill` / `section` / `griller`） |
| `setSpeed('slow'｜'fast'｜'real')` | 焼きの工程の早回し（約110倍）と実時間の切り替え（`slow` と `fast` はどちらも早回し） |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `fluxAt(cm)`, `perf()` | 高さごとの受ける熱の量（kW/m²）、描画コストと画素比 |

## 依頼文から変えたところ

- 焼きの工程は十数分かかるので、「約8倍のスロー」ではなく「早回し表示（約110倍）」にしました（14〜18.5秒の区間に工程全体が収まる倍率）。
- 事実確認の結果に合わせて、リード、字幕（0〜3秒、3〜7秒、7〜12秒、23〜27秒、27〜30秒）、工程③の説明、完了時の注記、グラフの注記を直しました（`FACT-CHECK.md`）。
