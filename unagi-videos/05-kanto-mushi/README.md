## 模型の中身（値はすべて原理を示すための模型の値）

- 白焼き：厚さ1.2cmの1片を、皮（0.1cm）・皮下の脂（0.15cm）・身に分け、厚さ方向24層の1次元熱伝導を陽解法（0.25秒刻み）で解きます。熱伝導率は身0.0785 W/(m·K)、脂はその0.5倍、皮は0.7倍。蒸す時間の目盛り（0〜40分）の中ほどで中心がしきい値を越えるように合わせた模型の値です。
- 蒸気の面：蒸し器の中は100℃。蒸気が表面で水に戻るときの熱の受け渡しを熱伝達率8,000 W/(m²·K)とし、表面の熱の釣り合い（凝縮 ↔ 身の中への伝導）から表面温度を求めます。下の面は簀の子に一部ふさがれる分（0.6）を掛けています。表面が100℃に近づくほど、受け取る熱は小さくなります。
- 比較の乾いた空気：同じ100℃、熱伝達率25 W/(m²·K)。湿った表面では熱が水分の蒸発に使われる分を、ルイスの関係による蒸発の式で差し引くので、表面は100℃に届きません（表面の水分が減ると蒸発も減ります）。40分後の中心は約50℃（蒸気では約95℃）。
- ほぐれ度：各層の温度が65〜80℃の帯（模型の値）のどこにあるかで進む速さを決め（65℃で0、80℃以上で最大）、時間で積分します。最大の速さなら6.3分で100%です。中心の層が100%になると「中心まで均一　やわらかく」（約23.5分）。落ちた余分な脂は、脂の層の温度に応じた速さの積分です。
- 蒸しすぎ：中心のほぐれ度の積分が100%を越えてからさらに165%分進むと（約33.9分）、「鰻のエッセンスが出切ります」の表示になります。
- 蒸気の粒：1,100粒を時刻だけで決まる経路で動かし、身に触れた粒は、その時点で表面が受け取っている熱の大きさに応じた確率で水に戻ります（琥珀の光 → 小さな水滴）。
- 箸で持ち上げた身：やわらかさに応じてたわみ、蒸しすぎのときはほぐれて皿に落ちます（模型のイメージ）。

## フック

| 名前 | 内容 |
| --- | --- |
| `ready` | 準備ができたかどうか |
| `setSteamTime(分)` | 蒸す時間を設定し、状態を同期で返す（中心温度・ほぐれ度・成功・失敗の判定まで反映済み） |
| `getState()` | 現在の状態を返す（同期）。`thresholds` にしきい値を越える時間、ほぐれ度100%の時間、蒸しすぎの時間 |
| `tap()` | お手本（0分から、中心まで均一にやわらかくなる時間まで自動で蒸す） |
| `setExploded(on)` | 分解表示の切り替え |
| `setCamera(name, instant)` | カメラの切り替え（`overview` / `inside` / `section` / `chopsticks`） |
| `setSpeed('slow'｜'real')` | お手本の早回し表示（約90倍）と実時間の切り替え（`slow` は早回し） |
| `setStyle('kanto'｜'kansai')` | 関東風と関西風の切り替え（関西風は蒸しの工程がないので、蒸気を止めて工程の違いを表示） |
| `renderDemoFrame(t)` | デモの時刻 `t` 秒のフレームを同期的に、決定的に描画する |
| `pause(on)`, `advance(sec)` | 検査用：自動の描画を止め、1/60秒刻みで進めてから1回描画する |
| `centerTempAt(分)`, `ovenCenterTempAt(分)`, `perf()` | 蒸気と乾いた空気の中心温度、描画コストと画素比 |

## 依頼文から変えたところ

- 蒸しは数十分かかるので、「約20倍のスロー」ではなく「早回し表示（約90倍）」にしました（しきい値を越えるまでと、中心まで均一になるまでが、それぞれ台本の区間に収まる倍率）。完了時に「蒸しの工程は、実際には20〜30分位です（それ以上かかることもあります）」を出し、実時間にも切り替えられます。
- 失敗の場面では、蒸し器の横の白い皿に取った身を箸で持ち上げ、ほぐれて落ちる様子を「模型のイメージ」として見せます。操作中は4秒後に目盛りが自動で戻り、元の状態に戻ります。
- 関東風と関西風の比較は、食感の言葉ではなく工程（背開き→白焼き→蒸す→たれをつけて焼く／腹開き→蒸さずにたれをつけて焼く）の違いとして示し、出典（農林水産省「うちの郷土料理」）を添えました。
