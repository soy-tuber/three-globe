## 使う前に

- **「もっと知る」は記入済み、ただし原文は未確認**：2026年9月に検索で出典を探して記入した。作業環境のネットワーク制限で原文のページを開けず、検索結果の要約で確かめている。公開前に、各リンク先の本文で文言と数値を確認する。
- **【注意】の付いた項目**：資料によって内容が異なるもの、事業者の解説記事で一次資料ではないもの、画面に出すか検討が必要なもの。特に次の3つ。
  - 06 の加熱条件（60℃・5分）は、厚生労働省のページの本文で必ず確認する。
  - 08 の保存温度（生鮮魚介類5℃以下）は大量調理施設向けの基準。自社の HACCP の計画に合わせる。
  - 10 の産卵場までの距離は、資料によって約2,000km と約3,000km に分かれる。
- **一次資料に差し替えたいもの**：03 と 05 と 07 は専門店や事業者の解説が中心。公的な資料や学術資料が見つかれば差し替える。
- **本体の数値は模型の値**：「物理」の節の数値は、原理を見せるための模型の値。画面にもそう注記する前提で書いている。
- **固定の部分は変えない**：技術の条件、文言の規則、フック、進め方は、ICカードの例と同じ。
