# 01 焼き台の煙はどこへ行くのか（排気フードと気流）

- 用途：店舗開発。物件選びや設計の打ち合わせ、投資判断の説明に使う
- 見る人：出店担当、設計者、オーナー、店長候補
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）

---

鰻店の焼き台の上で、煙と熱がどう流れ、排気フードがそれをどう捕まえるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、飲食店の出店や設計に関わる人に見てもらうことです。

# 見せたいこと
焼き台の煙は、熱で勝手に上へ昇っていく。フードはそれを「吸い上げている」のではなく、フードの口の近くでだけ働く弱い吸い込みで「受け止めている」。
吸い込みは、フードの口から離れると急に弱まる。そのため風量が足りないと、煙はフードの縁からあふれて客席へ流れ出す。
これを、光る気流の線と「フードの風量を上げる」という操作1つで体感させる。
最初の2秒で「焼き台」「排気フード」「立ち昇る光る煙」が一目で分かる絵にすること。

# 技術の条件
- index.html 1枚。three.js は importmap で https://cdn.jsdelivr.net/npm/three@0.183.2/ から読む

# 体験の流れ
① 初期状態：炭火の焼き台の上に蒲焼きが並び、細い煙の粒が立ち昇っている。上にはフードがあり、口のまわりに弱い吸い込みの流線が見える
② 操作：フードの風量を、フード上のつまみのドラッグで上げ下げする。ホイール、スライダー、↑↓キーでも同じ値が動く。つまみに触れたときだけ風量を操作し、それ以外のドラッグはカメラを回す
③ 変化：風量を上げるほど吸い込みの流線が太く明るくなり、煙の粒がフードへ曲がっていく。捕集率メーターが伸びる
④ しきい値を越えた瞬間：フードの縁での吸い込みの速さが煙の昇る速さを上回り、あふれていた煙が縁で折り返して全部フードに入る。縁の線が白く光り、そのあと煙の粒を約20倍のスローで追う
   ①発生 炭の熱で空気が軽くなる　②上昇 煙が熱と一緒に昇る　③接近 フードの口に近づく　④捕集 吸い込みにつかまる　⑤ろ過 フィルターで油を落とす　⑥排気 ダクトから外へ出る
⑤ 成功：短い低い「フォン」という音。表示に「捕集率 98%」を出す。客席側の空気は澄んだまま
⑥ 失敗・中断：給気口を閉じるボタンを押すと、店内の気圧が下がって実際の排気量が落ち、煙が客席へ流れ出す。入口の扉に「開けにくい」の表示（模型の気圧差×扉の面積から計算した力）と、扉のすき間から入る隙間風が出る。カメラが少し引いて客席側を見せ、数秒後に給気が戻ると元に戻る
⑦ 「分解」ボタン：焼き台（炭床／焼き網）、フード（本体／グリスフィルター／油受け）、ダクト、排気ファン、給気口が浮き上がる。グリスフィルターは3倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。焼き台は幅90×奥行40cm、フードの口は幅120×奥行60cm、焼き台からフードの口までの高さは90cm
- 煙の上昇：焼き台の上を、熱で昇る流れ（プルーム）として扱う。上昇速度は模型の値で約0.5m/s、高さとともに広がって遅くなる
- フードの吸い込み：口の中心からの距離 x での吸い込みの速さを、フランジ付きの口の経験式 V = Q / (0.75 × (10x² + A)) で求める（Q は風量、A は口の面積。フランジのない口の Dalla Valle の式 V = Q / (10x² + A) に、フランジで必要な排気風量が25％減る分を入れた形）
- 煙の粒：2つの流れの和の中を RK4 で追跡する。フードの外では吸い込みが急に弱まることが、流線の太さと明るさで分かるようにする
- 捕集率：フードの縁の各点で、吸い込みの速さが煙の上昇速度を上回るかどうかで判定し、その割合を捕集率とする。風量の目盛りの約6割付近でしきい値を越えるように模型の値を合わせ、上限は100%で頭打ちにする
- 給気不足：給気口を閉じると店内が負圧になり、ファンの実際の排気量が下がる。「扇風機の前をふさいだように風が細る」模式で表す
- NaN を出さない：長さ0のベクトルの正規化や、負の数の pow を避ける

# 見た目
- 舞台：開店前の夕方の鰻店の厨房。温かみのある暗い室内、焼き台の炭の赤、ステンレスのフードに映る炭火、奥にぼけた客席の明かり
- 材質：つや消しのステンレス、黒い鉄の焼き台、白木のカウンター
- 色の約束：
  - 気流は青白
  - 煙は薄い灰色で、炭の熱に近いほど琥珀
  - 捕集の成立は白い閃光
  - エラーは赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「焼き台の煙はどこへ行くのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：鰻を焼くと、たくさんの煙と熱が出ます。フードはそれを吸い上げているのではなく、昇ってきた煙を口の近くで受け止めています。風量を上げて、煙がフードに収まる瞬間を見てください。
- メーター：捕集率。線形。しきい値の破線に「煙がすべて収まる最低ライン」と付ける
- 小さなグラフ：フードからの距離と吸い込みの速さの曲線。現在値の点と、煙の上昇速度の横線を入れる。注記「フードの吸い込みは、口から離れると距離の2乗に近い割合で弱まります」を添える
- 処理タイムライン：スロー中は「経過 1.8秒」のような実時間カウンタを出し、捕集の完了時に「煙が焼き台からダクトに入るまで、この模型の実時間で約2秒です」と出す（秒数は模型の値）
- 小さなオシロスコープ：ファンの回転数と、店内の気圧の変化
- 操作ボタン：自動調整（風量を自動で上げ下げする）、分解、スロー／実時間、給気口の開閉、カメラ（全体／焼き台／フードの中／客席から）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や表示パネルの上には置かない
- 成功と失敗は、フードのそばに大きな吹き出しでも出す
- 注記：風量や速さは原理を示すための模型の値です。ダクトの中と屋上の設備は公開情報をもとにしたイメージです。煙の流れは目で見える速さに落とした模式表示です。給気口を閉じたときの動きも模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに風量・捕集率・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの5つだけを使う）
※ 2026年9月29日に、各リンク先の本文で文言と数値を確認した（FACT-CHECK.md）。

① 飲食店の厨房の排気フードや排気ダクトは油脂やほこりがたまりやすく、適切な維持管理を怠ると、火災や一酸化炭素中毒事故につながる危険性があります。（東京消防庁「飲食店の厨房設備等に係る火災予防対策ガイドライン」 https://www.tfd.metro.tokyo.lg.jp/kouhyou/kijun/chubou_kasai_guideline.html ）
② 東京都の火災予防条例は、天蓋（排気フード）、天蓋と接続する排気ダクトの内部、グリス除去装置（グリスフィルターなど）、火炎伝送防止装置を清掃し、火災予防上支障のないよう維持管理することを定めています。東京消防庁のガイドラインは、天蓋やグリス除去装置など外から確認できる部分は日常的に、排気ダクトの内部など外から確認しにくい部分は概ね1年ごとに点検し、その結果に基づいて清掃するよう示しています。点検の頻度は目安で、店舗の規模や機器の使用状態に応じて決めます。出店先が東京都以外なら、その自治体の条例と基準を確認します。（東京都「火災予防条例」第3条の2 https://www.reiki.metro.tokyo.lg.jp/reiki/reiki_honbun/g101RG00002311.html 、東京消防庁「飲食店の厨房設備等に係る火災予防対策ガイドライン」 https://www.tfd.metro.tokyo.lg.jp/content/000020602.pdf ）
③ 厨房は、においが客席などへ漏れないよう、給気量を排気量より少なめにして負圧ぎみにすることが多く、業務用電化厨房向けの設計指針は、給気量を排気量の85％程度としています。ただし、客席から厨房へ流れ込む空気を多くしすぎると、客席の空調の負荷や隙間風が増える原因になり得ます。（日本エレクトロヒートセンター「業務用電化厨房施設の換気設備設計指針［解説編］」 https://denkachubo.com/material/202110kanki_shishin_kaisetsu.pdf 、建材試験センター「業務用ちゅう（厨）房内空気環境を適正な状態に維持するための換気量の算定方法」 https://www.jtccm.or.jp/sites/default/files/2024-09/%E2%98%85%E6%A5%AD%E5%8B%99%E7%94%A8%E3%81%A1%E3%82%85%E3%81%86(%E5%8E%A8)%E6%88%BF%E5%86%85%E7%A9%BA%E6%B0%97%E7%92%B0%E5%A2%83%E3%82%92%E9%81%A9%E6%AD%A3%E3%81%AA%E7%8A%B6%E6%85%8B%E3%81%AB%E7%B6%AD%E6%8C%81%E3%81%99%E3%82%8B%E3%81%9F%E3%82%81%E3%81%AE%E6%8F%9B%E6%B0%97%E9%87%8F%E3%81%AE%E7%AE%97%E5%AE%9A%E6%96%B9%E6%B3%95.pdf ）
④ 外付け式フードでは、開口面では速い風速が得られても、距離が離れると吸引風速が激減します。フードの設計には Dalla Valle の式が用いられることが多く、自由空間に設けた外付け式円形フードの排風量は Q＝60・Vx・（10X²＋A）で求めます（Q：排風量［m³/min］、Vx：開口面から距離Xの点の風速［m/sec］、X：開口面からの距離［m］、A：開口面積［m²］）。フランジを取り付けると、同じ制御風速を得るのに必要な排気風量が25％減少するとされます。（厚生労働省「作業環境管理専門家の指導用マニュアル」 https://www.mhlw.go.jp/content/11300000/001240051.pdf 、産業医科大学雑誌「局所排気装置における外付け式フードの形状と風速の関係」 https://www.jstage.jst.go.jp/article/juoeh/33/4/33_KJ00007695226/_article/-char/ja/ 、産業衛生学雑誌「外付け式プレーン円形フードの排風量予測式」 https://www.jstage.jst.go.jp/article/sangyoeisei/59/1/59_16-018-C/_html/-char/ja 、空気調和・衛生工学会論文集「ポテンシャル流れの数値解析による円形フードの排気風量計算」 https://www.jstage.jst.go.jp/article/shase/48/319/48_41/_article/-char/ja/ ）
⑤ 環境省の飲食業向けの臭気対策マニュアルによると、飲食店のにおいの発生源の割合は調理臭が71％で（平成22年度の地方公共団体アンケート結果）、飲食店では調理臭が原因となって近隣から苦情が多いことが分かっています。（環境省「飲食業の方のための『臭気対策マニュアル』」 https://www.env.go.jp/air/akushu/manual/manual_01.pdf ）

# 検証用フックと録画モード
- window.__lab = { ready, setAirflow(割合0〜1), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setMakeupAir(open) }
  - setAirflow の直後の getState は、捕集率と成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　厨房全体の絵「鰻を焼くと、煙と熱が勢いよく昇っていきます」
  - 3〜7秒　フードの口へ寄る「フードは煙を吸い上げているのではなく、口の近くで受け止めています」
  - 7〜12秒　風量がゆっくり上がる「吸い込みは口から離れると、急に弱くなります」
  - 12〜14秒　しきい値を越える「縁の吸い込みが煙の勢いを上回った瞬間、煙はすべて収まります」
  - 14〜18.5秒　スローで煙の粒を追う「煙はフィルターで油を落としてから外へ出ていきます」
  - 18.5〜23秒　捕集完了と澄んだ客席「この模型では、焼き台からダクトまで約2秒です」
  - 23〜27秒　給気口を閉じる→煙があふれる「空気の入り口をふさぐと、フードは力を出せなくなります」
  - 27〜30秒　分解した引きの絵「だから出店では、排気と給気を一緒に設計します」
