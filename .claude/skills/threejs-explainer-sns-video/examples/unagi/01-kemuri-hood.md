# 01 焼き台の煙はどこへ行くのか（排気フードと気流）

- 用途：店舗開発。物件選びや設計の打ち合わせ、投資判断の説明に使う
- 見る人：出店担当、設計者、オーナー、店長候補
- 状態：サンプル。「もっと知る」の事実は出典を確認してから確定する（要確認）

---

鰻店の焼き台の上で、煙と熱がどう流れ、排気フードがそれをどう捕まえるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、飲食店の出店や設計に関わる人に見てもらうことです。

# 見せたいこと
焼き台の煙は、熱で勝手に上へ昇っていく。フードはそれを「吸い上げている」のではなく、フードの口の近くでだけ働く弱い吸い込みで「受け止めている」。
吸い込みは、フードの口から離れると急に弱まる。そのため風量が足りないと、煙はフードの縁からあふれて客席へ流れ出す。
これを、光る気流の線と「フードの風量を上げる」という操作1つで体感させる。
最初の2秒で「焼き台」「排気フード」「立ち昇る光る煙」が一目で分かる絵にすること。

# 技術の条件
- index.html 1枚。three.js は importmap で https://cdn.jsdelivr.net/npm/three@0.183.2/ から読む
- 外部の3Dモデルと画像は使わない。形はすべてコードで作り、模様は CanvasTexture で描く
- フォントは Google Fonts のみ。それ以外の外部通信はしない
- 60fps で動き、コンソールエラーは0件。ピクセル比は低めから始め、余裕があれば上げる

# 守ること
- 他人の作品のコードや見た目を参照・模倣しない
- 実在の店名、ロゴ、のれんの屋号、厨房機器メーカーの製品の形や配色は使わない
- 呼び名は「焼き台」「排気フード」「給気口」にする
- 画面の文言はすべて日本語。「！」と絵文字は使わない
- 「気流」と「風の流れ」を混ぜない。「排気」と「換気」を混ぜない（外へ出す動きは「排気」、取り入れる動きは「給気」）
- ダクトの中と屋上の設備は「公開情報をもとにしたイメージ」と明記する

# 体験の流れ
① 初期状態：炭火の焼き台の上に蒲焼きが並び、細い煙の粒が立ち昇っている。上にはフードがあり、口のまわりに弱い吸い込みの流線が見える
② 操作：フードの風量を、フード上のつまみのドラッグで上げ下げする。ホイール、スライダー、↑↓キーでも同じ値が動く。つまみに触れたときだけ風量を操作し、それ以外のドラッグはカメラを回す
③ 変化：風量を上げるほど吸い込みの流線が太く明るくなり、煙の粒がフードへ曲がっていく。捕集率メーターが伸びる
④ しきい値を越えた瞬間：フードの縁での吸い込みの速さが煙の昇る速さを上回り、あふれていた煙が縁で折り返して全部フードに入る。縁の線が白く光り、そのあと煙の粒を約20倍のスローで追う
   ①発生 炭の熱で空気が軽くなる　②上昇 煙が熱と一緒に昇る　③接近 フードの口に近づく　④捕集 吸い込みにつかまる　⑤ろ過 フィルターで油を落とす　⑥排気 ダクトから外へ出る
⑤ 成功：短い低い「フォン」という音。表示に「捕集率 98%」を出す。客席側の空気は澄んだまま
⑥ 失敗・中断：給気口を閉じるボタンを押すと、店内の気圧が下がって実際の排気量が落ち、煙が客席へ流れ出す。入口の扉に「開けにくい」の表示が出る。カメラが少し引いて客席側を見せ、数秒後に給気が戻ると元に戻る
⑦ 「分解」ボタン：焼き台（炭床／焼き網）、フード（本体／グリスフィルター／油受け）、ダクト、排気ファン、給気口が浮き上がる。グリスフィルターは3倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。焼き台は幅90×奥行40cm、フードの口は幅120×奥行60cm、焼き台からフードの口までの高さは90cm
- 煙の上昇：焼き台の上を、熱で昇る流れ（プルーム）として扱う。上昇速度は模型の値で約0.5m/s、高さとともに広がって遅くなる
- フードの吸い込み：口の中心からの距離 x での吸い込みの速さを、フランジ付きの口の経験式 V = Q / (10x² + A) で求める（Q は風量、A は口の面積）
- 煙の粒：2つの流れの和の中を RK4 で追跡する。フードの外では吸い込みが急に弱まることが、流線の太さと明るさで分かるようにする
- 捕集率：フードの縁の各点で、吸い込みの速さが煙の上昇速度を上回るかどうかで判定し、その割合を捕集率とする。風量の目盛りの約6割付近でしきい値を越えるように模型の値を合わせ、上限は100%で頭打ちにする
- 給気不足：給気口を閉じると店内が負圧になり、ファンの実際の排気量が下がる。「扇風機の前をふさいだように風が細る」模式で表す
- NaN を出さない：長さ0のベクトルの正規化や、負の数の pow を避ける

# 見た目
- 舞台：開店前の夕方の鰻店の厨房。温かみのある暗い室内、焼き台の炭の赤、ステンレスのフードに映る炭火、奥にぼけた客席の明かり
- 材質：つや消しのステンレス、黒い鉄の焼き台、白木のカウンター
- 色の約束：
  - 気流は青白
  - 煙は薄い灰色で、炭の熱に近いほど琥珀
  - 捕集の成立は白い閃光
  - エラーは赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「焼き台の煙はどこへ行くのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：鰻を焼くと、たくさんの煙と熱が出ます。フードはそれを吸い上げているのではなく、昇ってきた煙を口の近くで受け止めています。風量を上げて、煙がフードに収まる瞬間を見てください。
- メーター：捕集率。線形。しきい値の破線に「煙がすべて収まる最低ライン」と付ける
- 小さなグラフ：フードからの距離と吸い込みの速さの曲線。現在値の点と、煙の上昇速度の横線を入れる。注記「フードの吸い込みは、口から離れると距離の2乗に近い割合で弱まります」を添える
- 処理タイムライン：スロー中は「経過 1.8秒」のような実時間カウンタを出し、捕集の完了時に「煙が焼き台からダクトに入るまで、実際には約2秒です」と出す（秒数は模型の値）
- 小さなオシロスコープ：ファンの回転数と、店内の気圧の変化
- 操作ボタン：自動調整（風量を自動で上げ下げする）、分解、スロー／実時間、給気口の開閉、カメラ（全体／焼き台／フードの中／客席から）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や表示パネルの上には置かない
- 成功と失敗は、フードのそばに大きな吹き出しでも出す
- 注記：風量や速さは原理を示すための模型の値です。ダクトの中と屋上の設備は公開情報をもとにしたイメージです。煙の流れは目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに風量・捕集率・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実は下の候補のうち、出典を確認できたものだけを使う）
① 【要確認】飲食店の厨房のフードやダクトには、火災予防の観点から自治体の条例で基準が定められている（出典の候補：各自治体の火災予防条例、消防庁の資料）
② 【要確認】フードやダクトにたまった油は火災の原因になるため、グリスフィルターの定期的な清掃が求められている（出典の候補：消防庁、東京消防庁の資料）
③ 【要確認】排気と同じ量の給気がないと店内が負圧になり、扉が開けにくくなったり排気の能力が落ちたりする（出典の候補：建築設備の技術資料、空調衛生工学会の資料）
④ 【要確認】フランジ付きの口の吸い込みの速さを表す経験式（出典の候補：局所排気装置の設計資料、厚生労働省の局所排気装置に関する資料）
⑤ 【要確認】飲食店の臭気や煙は、地域によって悪臭防止法などの規制や近隣との協議の対象になる（出典の候補：環境省の悪臭防止法の資料）

# 検証用フックと録画モード
- window.__lab = { ready, setAirflow(割合0〜1), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setMakeupAir(open) }
  - setAirflow の直後の getState は、捕集率と成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　厨房全体の絵「鰻を焼くと、煙と熱が勢いよく昇っていきます」
  - 3〜7秒　フードの口へ寄る「フードは煙を吸い上げているのではなく、口の近くで受け止めています」
  - 7〜12秒　風量がゆっくり上がる「吸い込みは口から離れると、急に弱くなります」
  - 12〜14秒　しきい値を越える「縁の吸い込みが煙の勢いを上回った瞬間、煙はすべて収まります」
  - 14〜18.5秒　スローで煙の粒を追う「煙はフィルターで油を落としてから外へ出ていきます」
  - 18.5〜23秒　捕集完了と澄んだ客席「焼き台からダクトまで、実際には約2秒です」
  - 23〜27秒　給気口を閉じる→煙があふれる「空気の入り口をふさぐと、フードは力を出せなくなります」
  - 27〜30秒　分解した引きの絵「だから出店では、排気と給気を一緒に設計します」
