# 10 鰻はどこから来るのか（海を渡る長い旅）

- 用途：採用ブランディング（会社の理念の入口）。店舗・加工のどの採用にも使える
- 見る人：応募を考えている人、社員、取引先、お客さん
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）。資源の状況は年によって変わるので、最新の公的な資料に合わせる

---

ニホンウナギが海で生まれ、海流に乗って日本の川へたどり着くまでの旅を見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
私たちが食べている鰻は、日本から遠く離れた南の海で生まれる。透明な木の葉のような姿の赤ちゃんは、自分ではほとんど泳がず、海流に運ばれて日本の沿岸へやってくる。
途中で海流からこぼれた子は、たどり着けない。1匹の鰻が店に届くまでには、長い海の旅がある。
これを、光る海流と「時間を進める」という操作1つで体感させる。
最初の2秒で「地球儀」「南の海の産卵場」「日本へ向かう光る海流」が一目で分かる絵にすること。

# 技術の条件
- index.html 1枚。three.js は importmap で https://cdn.jsdelivr.net/npm/three@0.183.2/ から読む
- 外部の3Dモデルと画像は使わない。形はすべてコードで作り、模様は CanvasTexture で描く
  - 地球儀の陸地は、簡略化した海岸線の座標の配列をコードに持ち、CanvasTexture に描く。地図の画像やタイルは読み込まない
- フォントは Google Fonts のみ。それ以外の外部通信はしない
- 60fps で動き、コンソールエラーは0件。ピクセル比は低めから始め、余裕があれば上げる

# 体験の流れ
① 初期状態：夜の側から昇る朝日に照らされた地球儀。日本の南の海、マリアナ諸島の西の海に産卵場の小さな光があり、そこから西へ、そして北へ、日本へ向かう海流の光の帯が流れている
② 操作：時間（生まれてからの月数）を、地球儀の下の時間の輪のドラッグで進める。ホイール、スライダー、↑↓キーでも同じ値が動く。時間の輪に触れたときだけ時間を操作し、それ以外のドラッグは地球儀を回す
③ 変化：時間を進めるほど、光る子どもたちの粒が海流に乗って西へ広がり、一部が北へ曲がる黒潮に乗っていく。黒潮に乗れなかった粒は、流れから外れて薄れていく
④ しきい値を越えた瞬間：粒が大陸棚の縁に届くと、木の葉の形から細長いシラスウナギの形へ変わり、白い閃光。そのあと、川をのぼり、育ち、また海へ戻るまでの一生を約1万倍の早回しで見せる
   ①生まれる 南の海で卵から生まれる　②運ばれる 木の葉の形で海流に運ばれる　③変わる 沿岸でシラスウナギに変わる　④のぼる 川や河口にのぼる　⑤育つ 何年もかけて育つ　⑥帰る 大人になると産卵場へ帰る
⑤ 成功：「コーン」という澄んだ短い音。表示に「日本の沿岸にたどり着きました　海流に乗って数千kmの旅」を出す（日本と産卵場の距離は公的資料どうしで約2,000kmと約3,000kmに分かれるため、数値は出さない）
⑥ 失敗・中断：海流から外れた粒を選ぶボタンを押すと、その粒が黒潮に乗れずに、フィリピン沖で南へ向かう海流に運ばれていく軌跡が示される。表示が赤で「海流から外れました　たどり着けません」。カメラが少し引いて太平洋全体を見せ、数秒後に元に戻る
⑦ 「分解」ボタン：ニホンウナギの一生の姿が並んで浮き上がる（卵／木の葉の形の子（レプトセファルス）／シラスウナギ／クロコ／黄ウナギ／銀ウナギ）。小さい姿は拡大し、それぞれの倍率を明記する

# 物理（原理は正しく、数値は模型の値）
- 地球儀：半径100の球。緯度経度から3次元の座標に変換する
- 海流：北赤道海流（西向き）と黒潮（フィリピン沖で北へ曲がり、日本の南岸に沿って北東へ）を、緯度経度の上の滑らかな速度場として模型で作る。流れの強さは模型の値
- 粒の動き：各粒を、海流の速度場と小さな乱れ（乱数の種を固定したランダムウォーク）の和の中で RK4 で追跡する。粒は自分でほとんど泳がない前提にする
- 形の変化：粒が大陸棚の縁（模型の等深線）に届いた時点で、シラスウナギに変わったとみなす。届くまでの日数を記録する
- たどり着く割合：放った粒のうち、黒潮に乗って大陸棚の縁に届いた割合を数える。時間の目盛りの中ほどで最初の粒が届くように模型の値を合わせる
- 決定的な描画：粒の初期位置と乱れは乱数の種を固定し、renderDemoFrame(t) が同じ時刻に同じ絵を出すようにする
- NaN を出さない：極の近くでの座標変換、長さ0のベクトルの正規化、ゼロ除算を避ける

# 見た目
- 舞台：宇宙から見た夜明けの地球。深い藍色の海、ぼんやり光る大気の縁、遠くの星。日本の沿岸には、かすかな町の明かり
- 材質：地球儀の海はなめらかな深い藍色、陸地は落ち着いた灰緑色
- 色の約束：
  - 海流は青白の光の帯
  - 旅をする子どもたちの粒は琥珀
  - シラスウナギに変わる瞬間は白い閃光
  - 海流から外れた粒の警告は赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「鰻はどこから来るのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：私たちが食べている鰻は、日本から遠く離れた南の海で生まれます。小さな子どもたちは、海流に運ばれて日本の沿岸へやってきます。時間を進めて、その長い旅を見てください。
- メーター：たどり着いた子どもの割合。線形。しきい値の破線に「日本の沿岸に届き始めるライン」と付ける
- 小さなグラフ：生まれてからの月数と、産卵場からの距離の曲線。現在値の点と、大陸棚の縁の距離の横線を入れる。注記「子どもたちは自分ではほとんど泳がず、海流に運ばれていきます」を添える
- 処理タイムライン：早回し中は「経過 4か月」のような実時間カウンタを出し、一生の完了時に「1匹の鰻は、川や河口で5年から15年ほどかけて育ちます」と出す
- 小さなオシロスコープ：粒が乗っている場所の海流の速さの変化
- 操作ボタン：旅を再生（自動で時間を進める）、分解、早回し／実時間、外れた粒を追う、カメラ（地球全体／産卵場／黒潮／日本の河口）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や日本列島の上には置かない
- 成功と失敗は、日本の沿岸のそばに大きな吹き出しでも出す
- 注記：距離と日数は原理を示すための模型の値です。海流と旅の道すじは研究の成果をもとにした模式図です。粒の動きは目で見える速さに変えた模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに月数・たどり着いた割合・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの6つだけを使う）

④のレッドリストの区分は、汽水・淡水魚類の第5次レッドリストが公表されると変わる可能性があるので、公開の直前にもう一度確認する。

① ニホンウナギの産卵場は、マリアナ諸島の西にある西マリアナ海嶺の海山域と考えられ、その南端付近にまで広がっています。2009年5月の新月のころ、西マリアナ海嶺の南端部で、天然のウナギの卵が世界で初めて採集されました。（東京大学大気海洋研究所「人類が初めて目にした天然ウナギ卵」 https://www.aori.u-tokyo.ac.jp/research/news/2011/files/unagi20110202.pdf ）
② 生まれた子（レプトセファルス）は、透明で柳の葉のような形をしており、海流に乗って、数千km離れた東アジア沿岸の淡水・汽水域の生息地へ運ばれます。北赤道海流などを通って西へ運ばれ、フィリピン沖で黒潮に乗り、北へ運ばれていくあいだにシラスウナギへと姿を変えます。生息地へたどり着くには、フィリピン沖で、南へ向かう海流ではなく、北へ向かう黒潮に乗り換えることが必要だと考えられています。（水産庁・水産研究・教育機構「令和7年度 国際漁業資源の現況 83 ニホンウナギ」 https://kokushi.fra.go.jp/R07/R07_83_ELJ.pdf ）レプトセファルスの形は、産卵場から淡水の成育場まで、海流によって受け身で運ばれるための、浮かんで暮らすことへの適応と考えられています。（東京大学「研究成果『ニホンウナギの産卵地点の発見』」 https://www.u-tokyo.ac.jp/focus/ja/press/p01_180223.html ）
③ 川や河口で5年から15年ほどかけて育った鰻は、成熟すると銀ウナギになり、産卵のためにマリアナ諸島付近へ帰ると考えられています。（水産庁「ウナギをめぐる状況と対策について」令和8年7月 https://www.jfa.maff.go.jp/j/saibai/attach/pdf/unagi-279.pdf ）
④ ニホンウナギは、2013年2月に公表された環境省の第4次レッドリスト（汽水・淡水魚類）で、それまでの「情報不足」から「絶滅危惧IB類」に選定されました。2026年9月時点で最新の評価である環境省レッドリスト2020でも、絶滅危惧IB類に掲載されています。（環境省「第４次レッドリストの公表について（汽水・淡水魚類）」 https://www.env.go.jp/press/16264.html 、環境省「環境省レッドリスト2020の公表について」 https://www.env.go.jp/press/107905.html ）
⑤ 2010年に、水産総合研究センター（現在の水産研究・教育機構）が、ウナギの「完全養殖」に世界で初めて成功しました。完全養殖は、人工のシラスウナギを親まで育て、その親から得た卵をふ化させることです。水産研究・教育機構では現在、年間数万尾の人工のシラスウナギを生産できるようになりましたが、生産コストは、天然のシラスウナギの取引価格が高かった年と比べても約3倍で、卵からシラスウナギを大量に生産する技術はまだ実用化されていません。（水産総合研究センター 平成22年4月8日のプレスリリース（国立国会図書館インターネット資料収集保存事業の保存版） https://warp.ndl.go.jp/info:ndljp/pid/12853863/www.fra.affrc.go.jp/pressrelease/pr22/2204082/index.html 、水産庁「ウナギをめぐる状況と対策について」令和8年7月 https://www.jfa.maff.go.jp/j/saibai/attach/pdf/unagi-279.pdf ）
⑥ シラスウナギの国内の採捕量は、昭和30年代以降大きく減り、昭和50年代後半からは概ね5トンから30トンの間で推移しています。国内の採捕量が少ないと見込んだ養殖業者が多い年などには、海外からの輸入が増える傾向があります。養殖池に入れるシラスウナギの量（池入れ数量）は、日本・中国・韓国・チャイニーズ・タイペイの間で取り決めた制限をもとに、国内では農林水産大臣の許可のもとで、養殖業者ごとに上限が決められています。（水産庁「ウナギに関する情報」 https://www.jfa.maff.go.jp/j/saibai/unagi.html 、同ページ掲載の水産庁「ウナギをめぐる状況と対策について」令和8年7月 https://www.jfa.maff.go.jp/j/saibai/attach/pdf/unagi-279.pdf ）

# 検証用フックと録画モード
- window.__lab = { ready, setMonth(月数), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('fast'|'real'), followLost(on) }
  - setMonth の直後の getState は、粒の位置・たどり着いた割合・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　地球全体の絵「いつも食べている鰻は、どこで生まれるのでしょうか」
  - 3〜7秒　南の海の産卵場へ寄る「答えは、日本から遠く離れた南の海です」
  - 7〜12秒　時間がゆっくり進む「小さな子どもたちは、自分ではほとんど泳がず、海流に運ばれます」
  - 12〜14秒　大陸棚の縁に届く「日本の沿岸に近づくと、透明なシラスウナギに姿を変えます」
  - 14〜18.5秒　早回しで川をのぼり育つ「川や河口にのぼり、何年もかけて大きく育ちます」
  - 18.5〜23秒　一生の完了「育った鰻は、また生まれた南の海へ帰っていきます」
  - 23〜27秒　海流から外れた粒→たどり着けない「海流から外れた子どもたちは、たどり着けません」
  - 27〜30秒　一生の姿を並べた引きの絵「だから私たちは、1匹の鰻を大切に扱います」

# 進め方
実装したら Playwright でスクリーンショットを撮り、自分で見て直す作業を最低3回繰り返してください。
最初の画面、しきい値の瞬間、成功、失敗、分解、スマホ幅は必ず確認すること。
最後に 1920×1080・30fps で動画を書き出し、成功の瞬間に「コーン」、失敗の瞬間に「ピピピ」を ffmpeg で重ねてください。
そのうえで、字幕と絵が台本どおりかを確認してください。
