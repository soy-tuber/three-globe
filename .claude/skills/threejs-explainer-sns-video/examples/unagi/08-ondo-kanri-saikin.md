# 08 なぜ冷やして管理するのか（温度と細菌の増え方）

- 用途：加工現場と飲食の現場の衛生教育（HACCP の考え方の入門）
- 見る人：加工場の新人、厨房の新人、パート・アルバイトのスタッフ
- 状態：サンプル。「もっと知る」の事実は出典を確認してから確定する（要確認）。保管温度などの基準の数値は、必ず公的な出典の値を使う

---

食品の上で細菌がどう増えるのか、そして温度を下げるとなぜ増え方が遅くなるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
細菌は、1つが2つ、2つが4つと、倍々で増える。倍になるまでの時間は温度で大きく変わり、室温では短く、冷やすと長くなる。
倍々で増えるので、「少しの間だけ置いておいた」が、気づかないうちに大きな差になる。冷やすのは細菌を殺すためではなく、増える速さを落とすためだ。
これを、光る細菌の粒と「温度を変える」という操作1つで体感させる。
最初の2秒で「作業台の上の鰻の身」「冷蔵庫」「身の表面で増える光る粒」が一目で分かる絵にすること。

# 技術の条件
- index.html 1枚。three.js は importmap で https://cdn.jsdelivr.net/npm/three@0.183.2/ から読む
- 外部の3Dモデルと画像は使わない。形はすべてコードで作り、模様は CanvasTexture で描く
- フォントは Google Fonts のみ。それ以外の外部通信はしない
- 60fps で動き、コンソールエラーは0件。ピクセル比は低めから始め、余裕があれば上げる

- 実在の店名、企業名、ロゴ、冷蔵庫メーカーの製品の形や配色は使わない
- 呼び名は「細菌」「冷蔵庫」「温度管理」にする
- 画面の文言はすべて日本語。「！」と絵文字は使わない
- 「細菌」と「菌」と「ばい菌」を混ぜない（画面では「細菌」に統一する）。「増殖」と「増える」を混ぜない（画面では「増える」）
- 特定の食中毒の原因菌の名前は、出典で確認できたものだけを「もっと知る」に書き、画面の本体では一般的な「細菌」として扱う

- 保管温度の基準は、出典で確認した値だけを画面に出す。確認できるまでは「基準の温度」とだけ書く

# 体験の流れ
① 初期状態：作業台の上の鰻の身の表面に、光る細菌の粒がいくつか付いている。横には冷蔵庫と温度計がある。時計が静かに進んでいる
② 操作：置いておく場所の温度を、温度計のドラッグで上げ下げする。ホイール、スライダー、↑↓キーでも同じ値が動く。温度計に触れたときだけ温度を操作し、それ以外のドラッグはカメラを回す
③ 変化：温度を上げるほど、粒が分かれる間隔が短くなり、数のメーターが伸びる。温度を下げると、分かれる間隔が長くなる
④ しきい値を越えた瞬間：温度が基準の温度を越えると、粒の分かれ方が一気に速くなり、身の表面に赤い警告の縁が出る。そのあと、置きっぱなしにした数時間を約1,000倍の早回しで見せる
   ①付く 手や道具から細菌が付く　②待つ 最初はほとんど増えない　③分かれる 1つが2つに分かれる　④倍々 2、4、8と増えていく　⑤冷やす 冷蔵庫に入れると増える速さが落ちる　⑥守る 決めた温度と時間を記録して守る
⑤ 成功：冷蔵庫に入れて扉を閉めると、短い「ピッ」という音。表示に「増える速さ 大きく低下　温度記録 済み」を出す
⑥ 失敗・中断：作業台に置きっぱなしにするボタンを押すと、粒の数が倍々で膨らみ、メーターが赤に振り切れる。表示が赤で「置きっぱなし　すぐに冷蔵庫へ」。カメラが少し引いて作業台全体と時計を見せ、数秒後に冷蔵庫へ戻す
⑦ 「分解」ボタン：温度管理の仕組み（冷蔵庫の本体／庫内の温度計／温度の記録表／真空包装／作業台の消毒）が浮き上がる。細菌の粒は大きく拡大し、「模式図」と明記する

# 物理（原理は正しく、数値は模型の値）
- ここでの「物理」は、細菌の増え方の数理モデルとする
- 増え方：N(t) = N0 · 2^(t / 倍加時間)。最初の「待つ」時間（誘導期）を入れたモデルにする
- 倍加時間と温度の関係：平方根モデル √(増える速さ) = b·(T − Tmin) で表す（b と Tmin は模型の値）。Tmin 以下では増えない
- 数は対数の目盛りで見せ、画面の粒の数は対数に合わせて間引いた模式表示にする。粒が分かれるアニメーションの間隔は、計算した倍加時間に比例させる
- しきい値：模型の値で、基準の温度を越えると増える速さが一定の値を上回るように合わせる。粒の数は上限で頭打ちにし、「数えきれない」と表示する
- 早回しでは、renderDemoFrame(t) が決定的になるよう、粒の分かれる時刻を乱数の種を固定して事前に決めておく
- NaN を出さない：負の数の平方根、log(0)、ゼロ除算を避ける

# 見た目
- 舞台：夜の加工場の作業場。白い照明、ステンレスの作業台、奥に大きな冷蔵庫の扉。拡大した部分は、身の表面のなめらかな起伏の上に光る粒が並ぶ世界
- 材質：ステンレス、白い樹脂のまな板、透明な真空包装
- 色の約束：
  - 細菌の粒は青白
  - 温かさ（室温）は琥珀の空気のゆらぎ
  - 冷蔵庫に入った瞬間は白い閃光
  - 基準を越えた警告は赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「なぜ冷やして管理するのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：細菌は、1つが2つ、2つが4つと倍々で増えます。冷やすのは、細菌を殺すためではなく、増える速さを落とすためです。温度を変えて、その違いを見てください。
- メーター：細菌の数（対数の目盛り）。しきい値の破線に「基準の温度を越えたライン」と付ける
- 小さなグラフ：温度と、倍になるまでの時間の曲線。現在値の点と、基準の温度の縦線を入れる。注記「温度が上がるほど、細菌が倍になるまでの時間は短くなります」を添える
- 処理タイムライン：早回し中は「経過 2時間10分」のような実時間カウンタを出し、完了時に「置きっぱなしの数時間で、数は何倍にもなります」と出す
- 小さなオシロスコープ：温度の記録と、細菌の数の変化
- 操作ボタン：冷蔵庫へ（自動で正しく片付ける）、分解、早回し／実時間、置きっぱなし、カメラ（全体／身の表面／冷蔵庫の中／記録表）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や警告の表示の上には置かない
- 成功と失敗は、冷蔵庫のそばに大きな吹き出しでも出す
- 注記：温度と時間は原理を示すための模型の値です。細菌の粒は模式図で、大きさと数は実際と異なります。増え方は目で見える速さに変えた模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに温度・数・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実は下の候補のうち、出典を確認できたものだけを使う）
① 【要確認】2021年6月から、原則としてすべての食品等事業者に HACCP に沿った衛生管理が求められている（出典の候補：厚生労働省の HACCP のページ）
② 【要確認】生の魚介類の保管温度の目安（出典の候補：厚生労働省「大量調理施設衛生管理マニュアル」。数値は出典どおりに書く）
③ 【要確認】多くの細菌は室温付近でよく増え、低温では増える速さが落ちる（出典の候補：食品衛生の教科書、厚生労働省の食中毒予防の資料）
④ 【要確認】食中毒予防の三原則「つけない、増やさない、やっつける」（出典の候補：厚生労働省、政府広報オンライン）
⑤ 【要確認】魚介類に関係する食中毒の原因菌の例と、その性質（出典の候補：厚生労働省、食品安全委員会の資料）

# 検証用フックと録画モード
- window.__lab = { ready, setTemperature(℃), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('fast'|'real'), leaveOut(on) }
  - setTemperature の直後の getState は、倍加時間・細菌の数・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　作業台と冷蔵庫の全体の絵「食品を冷やして管理するのには、理由があります」
  - 3〜7秒　身の表面へ寄る「身の表面には、目に見えない細菌が付いています」
  - 7〜12秒　温度がゆっくり上がる「細菌は、1つが2つ、2つが4つと倍々で増えます」
  - 12〜14秒　基準の温度を越える「温度がある線を越えると、増える速さは一気に上がります」
  - 14〜18.5秒　冷蔵庫へ入れる「冷やすと、細菌が倍になるまでの時間がぐっと延びます」
  - 18.5〜23秒　温度を記録する「冷やすのは殺すためではなく、増える速さを落とすためです」
  - 23〜27秒　置きっぱなし→数が膨らむ「少しの置きっぱなしでも、数は倍々で膨らみます」
  - 27〜30秒　分解した温度管理の仕組みの絵「だから温度と時間を決めて、毎日記録します」
