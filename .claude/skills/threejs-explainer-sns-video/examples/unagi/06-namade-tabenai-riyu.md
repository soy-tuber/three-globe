# 06 なぜ鰻は生で食べないのか（血液の毒と加熱）

- 用途：飲食の現場と加工現場の安全教育。お客さん向けの豆知識にも使える
- 見る人：新人の厨房スタッフ、加工場の作業者、お客さん
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）。毒と安全に関わる題材なので、数値と対処法は必ず公的な出典に合わせる

---

鰻の血液に含まれる毒のたんぱく質が、加熱によってどう壊れて無毒になるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
鰻の血液には毒のたんぱく質が含まれている。だから鰻は、ふつう刺身では食べず、火を通して食べる。
多くのたんぱく質は、決まった形に折りたたまれて働く。この毒もたんぱく質で、熱を加えると形が変わり（変性）、毒としての働きを失う（60℃、5分の加熱で完全に毒性を失う：厚生労働省）。
これを、光る毒のたんぱく質の模型と「温度を上げる」という操作1つで体感させる。
最初の2秒で「鰻の身」「血液の中に浮かぶ光るたんぱく質」「温度計」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：まな板の上の鰻の身の一部が拡大され、血液のしずくの中に、折りたたまれた毒のたんぱく質の模式図がいくつも浮かんでいる。たんぱく質は赤く脈打っている
② 操作：加熱の温度を、温度計のドラッグで上げ下げする。ホイール、スライダー、↑↓キーでも同じ値が動く。温度計に触れたときだけ温度を操作し、それ以外のドラッグはカメラを回す
③ 変化：温度を上げるほど、たんぱく質の模式図が激しく揺れ始める。「毒として働くたんぱく質の割合」のメーターはまだ下がらない
④ しきい値を越えた瞬間：温度が変性の温度帯に入ると、折りたたまれたたんぱく質がひもがほどけるように広がり、赤い光が消えて白い閃光。そのあと、加熱の時間とともに割合が下がっていく様子を約30倍のスローで見せる
   ①折りたたみ 決まった形に折りたたまれている　②揺れる 熱で分子が激しく動く　③ほどける 形を保つ結びつきが切れる　④広がる ひものように伸びる　⑤働きを失う 毒として働かなくなる　⑥安全 加熱した鰻は安心して食べられる
⑤ 成功：「チン」という短い音。表示に「毒として働く割合 0%　加熱済み」を出す
⑥ 失敗・中断：捌く作業の場面に切り替え、「生の血が飛ぶと」ボタンを押すと、血のしずくが目の方向へ飛ぶ軌跡が赤く示される。表示が赤で「目に入ると激しい灼熱感を覚えるとともに、結膜炎、流涙、まぶたの腫れが引き起こされます」（厚生労働省の原文どおり。対処法は書かない）。カメラが少し引いて作業台全体を見せ、数秒後に元の場面に戻る
⑦ 「分解」ボタン：捌き場の設備（まな板／目打ち／手洗い場）と、たんぱく質の模式図の構造（折りたたみ／結びつき／ひも）が浮き上がる。たんぱく質は大きく拡大し、「模式図、大きさは実際と異なる」と明記する

# 物理（原理は正しく、数値は模型の値）
- たんぱく質の変性を、1次反応の速度論で扱う：d(割合)/dt = −k(T)·割合
- 速度定数は、アレニウスの式 k(T) = A·exp(−Ea/RT) で求める（A と Ea は模型の値）。温度帯を越えると k が急に大きくなることを、グラフで見せる
- 「毒として働く割合」は、加熱の温度と時間の履歴を積分して求める。温度が低いままだと、時間をかけても割合がほとんど下がらないことが分かるようにする
- 模型の値は、出典で確認した加熱条件（60℃、5分：厚生労働省）で割合がほぼ0になるように合わせる。しきい値の破線（形がほどけ始める温度）は模型の値とし、60℃を当てはめない
- たんぱく質の模式図は、ばねでつないだ粒の鎖として作る。温度に応じて揺れの大きさを変え、変性するとばねの一部を切って広げる
- 飛ぶ血のしずくの軌跡は、放物運動の模式表示とする
- NaN を出さない：exp のあふれ、ゼロ除算、長さ0のベクトルの正規化を避ける

# 見た目

- 材質：白いまな板、ステンレス
- 色の約束：
  - 毒として働くたんぱく質は赤く脈打つ光
  - 加わる熱は琥珀
  - 変性の瞬間は白い閃光
  - 危険の警告は赤（たんぱく質の赤とは形で区別し、警告は枠と文字で示す）
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「なぜ鰻は生で食べないのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：鰻の血液には、毒のたんぱく質が含まれています。でも加熱すると、たんぱく質の形がほどけて毒として働かなくなります。温度を上げて、その瞬間を見てください。
- メーター：毒として働くたんぱく質の割合。線形。しきい値の破線に「形がほどけ始める温度」と付ける
- 小さなグラフ：温度と、ほどける速さの曲線。現在値の点と、しきい値の縦線を入れる。注記「ある温度を越えると、たんぱく質がほどける速さは急に上がります」を添える
- 処理タイムライン：スロー中は「経過 1分20秒」のような実時間カウンタを出し、完了時に「60℃、5分の加熱で、完全に毒性を失います」と出す
- 小さなオシロスコープ：温度の変化と、割合の減り方
- 操作ボタン：加熱（自動で適切に加熱する）、分解、スロー／実時間、生の血が飛ぶと（捌く場面の切り替え）、カメラ（全体／血液の中／たんぱく質／作業台）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や警告の表示の上には置かない
- 成功と失敗は、温度計のそばに大きな吹き出しでも出す
- 注記：60℃、5分は厚生労働省の資料の値です。それ以外の温度と速さは、原理を示すための模型の値です。たんぱく質の形は模式図で、実際の立体構造とは異なります。変化は目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに温度・割合・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの3つだけを使う）
※ 2026年9月29日に、各リンク先の本文で文言と数値を確認した（FACT-CHECK.md）。

① ウナギ目魚類（ウナギ、アナゴ、ハモ、ウツボ）は、血液（血清）に毒があります。ウナギの血清の毒は、100 kDaのたんぱく質です。（厚生労働省「自然毒のリスクプロファイル：魚類：血清毒」 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/poison/animal_06.html ）
② ウナギ毒およびマアナゴ毒は、いずれも60℃、5分の加熱で完全に毒性を失います。通常の加熱調理をすれば、食品衛生上の問題はありません。（厚生労働省「自然毒のリスクプロファイル：魚類：血清毒」詳細版 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/poison/animal_det_06.html 、概要版 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/poison/animal_06.html ）加熱で毒性を失うのは、毒のたんぱく質が熱で変性するためと説明されています。（大日本水産会 魚食普及推進センター「ウナギとアナゴに毒があっても食べられるのはナゼ？」 https://osakana.suisankai.or.jp/health_safe/7957 ）東京都島しょ農林水産総合センターは「ウナギは血液に毒があるため刺身では食べない。しかし、この毒は加熱分解するので、蒲焼きなどに調理すれば問題ない」としています。（東京都島しょ農林水産総合センター「ウナギ」 https://www.ifarc.metro.tokyo.lg.jp/archive/27,930,55,225.html ）一般に、たんぱく質は折りたたまれた立体的な形で特有の働きをし、熱などで形が壊れると働きを失います（変性）。多くのたんぱく質は、特定の形に折りたたまれて初めて働きます。（名古屋学芸大学 管理栄養学部「タンパク質の変性と消化」 https://nutrition.nuas.ac.jp/tips/000082.html 、東京大学 新井研究室「研究内容」 https://folding.c.u-tokyo.ac.jp/research_folding.html ）
③ 血液が目や口、傷口に入ると局所的な炎症が引き起こされます。目に入ると激しい灼熱感を覚えるとともに、結膜炎、流涙、まぶたの腫れが引き起こされます。目に異物が入った感じは数日残ります。口に入ると灼熱感や粘膜の発赤、流涎が、傷口に入ると炎症、化膿、浮腫などが引き起こされます。（厚生労働省「自然毒のリスクプロファイル：魚類：血清毒」詳細版 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/poison/animal_det_06.html ）

## 社内教育用（画面には出さない）
④ ウナギの新鮮な血液を大量に飲んだ場合、下痢、嘔吐、皮膚の発疹、チアノーゼ、無気力症、不整脈、衰弱、感覚異常、麻痺、呼吸困難が引き起こされ、死亡することもあるといわれています。ただし、わが国では食中毒の正式記録はありません。普通の食生活をしていれば、ウナギ目魚類の血清毒による食中毒は考えられませんが、興味半分にもウナギ目魚類の血液（血清）を飲んではいけません。（厚生労働省「自然毒のリスクプロファイル：魚類：血清毒」詳細版 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/shokuhin/syokuchu/poison/animal_det_06.html 。概要版は「死亡することもある。」と言い切っている）

# 検証用フックと録画モード
- window.__lab = { ready, setTemperature(℃), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setSplash(on) }
  - setSplash(on) は生の血が飛ぶ場面の切り替え。setGoggles(on) は互換のため残し、setSplash(!on) と同じ動きにする
  - setTemperature の直後の getState は、速度定数・毒として働く割合・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　まな板と鰻の全体の絵「鰻を刺身で見かけないのには、理由があります」
  - 3〜7秒　血液の中へ寄る「鰻の血液には、毒のたんぱく質が含まれています」
  - 7〜12秒　温度がゆっくり上がる「多くのたんぱく質は、決まった形に折りたたまれて働きます」
  - 12〜14秒　しきい値を越える「ある温度を越えた瞬間、その形がほどけ始めます」
  - 14〜18.5秒　スローで割合が下がる「ほどけたたんぱく質は、もう毒として働きません」
  - 18.5〜23秒　加熱の完了「だから火を通した鰻は、安心して食べられます」
  - 23〜27秒　捌く作業で生の血が目の方へ飛ぶ→警告「ただし捌くときは、生の血が目に入らないよう注意が必要です」
  - 27〜30秒　分解した捌き場と模式図の絵「だから、火を通すことと、捌くときの生の血への注意が大切です」
