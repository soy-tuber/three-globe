# 06 なぜ鰻は生で食べないのか（血液の毒と加熱）

- 用途：飲食の現場と加工現場の安全教育。お客さん向けの豆知識にも使える
- 見る人：新人の厨房スタッフ、加工場の作業者、お客さん
- 状態：サンプル。「もっと知る」の事実は出典を確認してから確定する（要確認）。毒と安全に関わる題材なので、数値と対処法は必ず公的な出典に合わせる

---

鰻の血液に含まれる毒のたんぱく質が、加熱によってどう壊れて無毒になるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
鰻の血液には毒のたんぱく質が含まれている。だから鰻は刺身では食べず、必ず火を通す。
たんぱく質は、決まった形に折りたたまれているときだけ毒として働く。熱を加えると、ある温度を越えたところで形がほどけ、毒としての働きを失う。
これを、光る毒のたんぱく質の模型と「温度を上げる」という操作1つで体感させる。
最初の2秒で「鰻の身」「血液の中に浮かぶ光るたんぱく質」「温度計」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：まな板の上の鰻の身の一部が拡大され、血液のしずくの中に、折りたたまれた毒のたんぱく質の模式図がいくつも浮かんでいる。たんぱく質は赤く脈打っている
② 操作：加熱の温度を、温度計のドラッグで上げ下げする。ホイール、スライダー、↑↓キーでも同じ値が動く。温度計に触れたときだけ温度を操作し、それ以外のドラッグはカメラを回す
③ 変化：温度を上げるほど、たんぱく質の模式図が激しく揺れ始める。「毒として働くたんぱく質の割合」のメーターはまだ下がらない
④ しきい値を越えた瞬間：温度が変性の温度帯に入ると、折りたたまれたたんぱく質がひもがほどけるように広がり、赤い光が消えて白い閃光。そのあと、加熱の時間とともに割合が下がっていく様子を約30倍のスローで見せる
   ①折りたたみ 決まった形のときだけ毒として働く　②揺れる 熱で分子が激しく動く　③ほどける 形を保つ結びつきが切れる　④広がる ひものように伸びる　⑤働きを失う 毒として働かなくなる　⑥安全 加熱した鰻は安心して食べられる
⑤ 成功：「チン」という短い音。表示に「毒として働く割合 0%　加熱済み」を出す
⑥ 失敗・中断：捌く作業の場面に切り替え、保護メガネを外したまま作業するボタンを押すと、血のしずくが目の方向へ飛ぶ軌跡が赤く示される。表示が赤で「目に入ると炎症を起こします　保護メガネを着けてください」。カメラが少し引いて作業台全体を見せ、数秒後に保護メガネを着けた状態に戻る
⑦ 「分解」ボタン：捌き場の安全装備（保護メガネ／手袋／まな板／目打ち／手洗い場）と、たんぱく質の模式図の構造（折りたたみ／結びつき／ひも）が浮き上がる。たんぱく質は大きく拡大し、「模式図、大きさは実際と異なる」と明記する

# 物理（原理は正しく、数値は模型の値）
- たんぱく質の変性を、1次反応の速度論で扱う：d(割合)/dt = −k(T)·割合
- 速度定数は、アレニウスの式 k(T) = A·exp(−Ea/RT) で求める（A と Ea は模型の値）。温度帯を越えると k が急に大きくなることを、グラフで見せる
- 「毒として働く割合」は、加熱の温度と時間の履歴を積分して求める。温度が低いままだと、時間をかけても割合がほとんど下がらないことが分かるようにする
- 模型の値は、出典で確認した加熱条件（温度と時間）で割合がほぼ0になるように合わせる。出典で確認できるまでは、画面に具体的な温度と時間の数値を出さない
- たんぱく質の模式図は、ばねでつないだ粒の鎖として作る。温度に応じて揺れの大きさを変え、変性するとばねの一部を切って広げる
- 飛ぶ血のしずくの軌跡は、放物運動の模式表示とする
- NaN を出さない：exp のあふれ、ゼロ除算、長さ0のベクトルの正規化を避ける

# 見た目
- 舞台：清潔な鰻店の仕込み場。白いタイルの壁、明るい照明、ステンレスの作業台。拡大した部分は、暗い背景に浮かぶ半透明の液体の世界
- 材質：白いまな板、ステンレス、透明な保護メガネ
- 色の約束：
  - 毒として働くたんぱく質は赤く脈打つ光
  - 加わる熱は琥珀
  - 変性の瞬間は白い閃光
  - 危険の警告は赤（たんぱく質の赤とは形で区別し、警告は枠と文字で示す）
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「なぜ鰻は生で食べないのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：鰻の血液には、毒のたんぱく質が含まれています。でも加熱すると、たんぱく質の形がほどけて毒として働かなくなります。温度を上げて、その瞬間を見てください。
- メーター：毒として働くたんぱく質の割合。線形。しきい値の破線に「形がほどけ始める温度」と付ける
- 小さなグラフ：温度と、ほどける速さの曲線。現在値の点と、しきい値の縦線を入れる。注記「ある温度を越えると、たんぱく質がほどける速さは急に上がります」を添える
- 処理タイムライン：スロー中は「経過 1分20秒」のような実時間カウンタを出し、完了時に「十分に加熱すれば、毒として働くたんぱく質は残りません」と出す
- 小さなオシロスコープ：温度の変化と、割合の減り方
- 操作ボタン：加熱（自動で適切に加熱する）、分解、スロー／実時間、保護メガネの着け外し、カメラ（全体／血液の中／たんぱく質／作業台）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や警告の表示の上には置かない
- 成功と失敗は、温度計のそばに大きな吹き出しでも出す
- 注記：温度と速さは原理を示すための模型の値です。たんぱく質の形は模式図で、実際の立体構造とは異なります。変化は目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに温度・割合・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実は下の候補のうち、出典を確認できたものだけを使う）
① 【要確認】鰻などの血清には毒のたんぱく質（イクシオトキシン）が含まれる（出典の候補：厚生労働省「自然毒のリスクプロファイル」）
② 【要確認】この毒は加熱によって働きを失う。加熱の条件（温度と時間）（出典の候補：厚生労働省、食品安全委員会の資料。数値は出典どおりに書く）
③ 【要確認】生の血液が目に入ると結膜炎などを起こすことがある。そのときの対処（出典の候補：厚生労働省の自然毒の資料、中毒情報センター）
④ 【要確認】大量の生の血液を飲んだ場合の症状の報告（出典の候補：厚生労働省の自然毒の資料。症状は出典の表現どおりに書く）
⑤ 【要確認】たんぱく質の変性は、熱によって立体構造がほどけることで起こる（出典の候補：生化学の教科書）

# 検証用フックと録画モード
- window.__lab = { ready, setTemperature(℃), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setGoggles(on) }
  - setTemperature の直後の getState は、速度定数・毒として働く割合・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　まな板と鰻の全体の絵「鰻を刺身で見かけないのには、理由があります」
  - 3〜7秒　血液の中へ寄る「鰻の血液には、毒のたんぱく質が含まれています」
  - 7〜12秒　温度がゆっくり上がる「たんぱく質は、決まった形のときだけ毒として働きます」
  - 12〜14秒　しきい値を越える「ある温度を越えた瞬間、その形がほどけ始めます」
  - 14〜18.5秒　スローで割合が下がる「ほどけたたんぱく質は、もう毒として働きません」
  - 18.5〜23秒　加熱の完了「だから火を通した鰻は、安心して食べられます」
  - 23〜27秒　捌く作業で保護メガネを外す→警告「ただし捌くときは、生の血が目に入らないよう注意が必要です」
  - 27〜30秒　分解した安全装備の絵「だから職人は、加熱と保護具の両方を欠かしません」
