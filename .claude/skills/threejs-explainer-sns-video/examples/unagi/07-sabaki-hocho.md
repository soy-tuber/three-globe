# 07 鰻を捌くとき、包丁の中で何が起きているか

- 用途：加工現場の採用（職人の技の魅力）と、捌きの新人教育・安全教育
- 見る人：応募を考えている人、加工場の新人、飲食の現場の新人
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）

---

鰻を捌くときに、包丁の刃先にどんな力がかかり、刃の角度が骨と身の分かれ方をどう決めるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
刃は、狭い刃先に力を集めることで身を切っている。同じ力でも、刃先が細いほど、そこにかかる圧力は大きくなる。
骨から身をきれいに外せるかどうかは、力の強さではなく、背骨に対する刃の角度で決まる。角度がほんの少しずれるだけで、骨に身が残るか、骨ごと切ってしまう。
これを、光る刃先の圧力と「刃の角度を変える」という操作1つで体感させる。
最初の2秒で「まな板の上の鰻」「包丁」「刃先に集まる光る圧力」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：まな板の上に、目打ちで頭を留めた鰻が置かれ、体の断面が半透明で見えている。鰻裂き包丁の刃先が背の側に当てられ、刃先に光る圧力の点が集まっている
② 操作：刃の角度（背骨の面に対する傾き）を、包丁の柄のドラッグで変える。ホイール、スライダー、↑↓キーでも同じ値が動く。柄に触れたときだけ角度を操作し、それ以外のドラッグはカメラを回す
③ 変化：角度を背骨の面に近づけるほど、刃の進む道が背骨に沿い、「骨に残る身の量」のメーターが下がっていく
④ しきい値を越えた瞬間：角度が許容の範囲に入ると、刃の道が背骨の面にぴたりと沿い、背骨の線が白く光る。そのあと約10倍のスローで、捌きの工程を見せる
   ①留める 目打ちで頭をまな板に留める　②入れる 背から刃を入れる　③沿わせる 背骨に沿って刃を進める　④開く 身を開く　⑤外す 背骨を外す　⑥整える ヒレを落とす
⑤ 成功：「スッ」という短い音。表示に「骨に残った身 わずか　きれいに開けました」を出す
⑥ 失敗・中断：角度が大きくずれたまま進めると、刃が背骨に当たって止まる、または身が骨に厚く残る。表示が赤で「角度がずれています」。刃が滑る方向に手がある場合は、赤い軌跡で「刃の進む先に手を置かない」と示す。カメラが少し引いて手元全体を見せ、数秒後に角度を戻すと元に戻る
⑦ 「分解」ボタン：鰻の体の構造の模式図（皮／身／背骨／腹骨／背ビレ・尻ビレ／内臓の位置）と、道具（鰻裂き包丁／目打ち／まな板／切創防止の手袋）が浮き上がる。刃先の断面は20倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。鰻は長さ60cm、背骨の太さ約0.4cm（模型の値）
- 刃先の圧力：p = F / (刃先の接触面積)。刃先の幅（模型の値）を小さくするほど、同じ力で圧力が大きくなることを、刃先の拡大図とグラフで見せる
- 切れる条件：刃先の圧力が身の組織を切る限界の値（模型の値）を越えたところだけが切れる。背骨はより大きな限界の値を持ち、刃は背骨に当たると止まるか滑る
- 刃の道：刃の角度と背骨の面の角度の差 Δθ から、刃が進むにつれて背骨からの距離がどれだけ離れるかを計算し、骨に残る身の量とする（進んだ距離 × tan Δθ を積分する模型）
- 許容の範囲：角度の目盛りの中ほどで、骨に残る身がしきい値を下回るように模型の値を合わせる
- 刃の滑り：刃が背骨に浅い角度で当たると、硬いものに沿って滑る方向の力が生まれる。その向きを赤い軌跡で示す
- NaN を出さない：tan の発散（90°付近）、ゼロ除算、長さ0のベクトルの正規化を避ける

# 見た目
- 舞台：早朝の加工場の捌き場。白い照明、ステンレスの作業台、水が流れる音が聞こえそうな清潔な空間
- 材質：使い込んだ白木のまな板、鈍く光る鋼の刃、鉄の目打ち
- 色の約束：
  - 刃先の圧力は青白の光の点
  - 切れていく道は琥珀の線
  - 背骨に沿った瞬間は白い閃光
  - 手への危険と失敗は赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「鰻を捌くとき、包丁の中で何が起きているか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：鰻を捌く職人の手元では、力ではなく角度がものを言います。刃を背骨にぴたりと沿わせると、骨に身を残さず開けます。刃の角度を変えて、その一点を探してみてください。
- メーター：骨に残る身の量。線形。しきい値の破線に「きれいに開ける範囲」と付ける
- 小さなグラフ：刃の角度のずれと、骨に残る身の量の曲線。現在値の点と、許容の範囲の帯を入れる。注記「角度がわずかにずれるだけで、残る身は急に増えます」を添える
- 処理タイムライン：スロー中は「経過 8秒」のような実時間カウンタを出し、完了時に「生きた鰻を捌くのは難しく、熟練を要する仕事です」と出す
- 小さなオシロスコープ：刃先の圧力と、刃の角度のずれの時間変化
- 操作ボタン：お手本（職人の角度の動かし方を自動で再生）、分解、スロー／実時間、カメラ（全体／刃先／体の断面／職人の目線）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や刃先の拡大図の上には置かない
- 成功と失敗は、まな板のそばに大きな吹き出しでも出す
- 注記：力と角度は原理を示すための模型の値です。体の構造は模式図で、刃の力の分布は模型による計算のイメージです。刃の動きは目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに角度・残る身の量・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# 検証用フックと録画モード
- window.__lab = { ready, setAngle(度), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real') }
  - setAngle の直後の getState は、刃先の圧力・骨に残る身の量・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　まな板と鰻と包丁の全体の絵「鰻を捌く職人の手元を、のぞいてみます」
  - 3〜7秒　刃先へ寄る「刃は、細い刃先に力を集めて身を切っています」
  - 7〜12秒　刃の角度がゆっくり変わる「きれいに開けるかどうかは、力ではなく角度で決まります」
  - 12〜14秒　許容の範囲に入る「刃が背骨にぴたりと沿った瞬間、身は骨から離れていきます」
  - 14〜18.5秒　スローで捌きの工程「背から刃を入れ、背骨に沿わせて一気に開きます」
  - 18.5〜23秒　きれいに開いた身「この角度を保てば、骨に残る身はわずかです」
  - 23〜27秒　角度がずれる→骨に身が残る、手への危険「角度がずれると身が残り、刃が思わぬ方向へ滑ります」
  - 27〜30秒　分解した引きの絵「だから捌きは、熟練を要する技です」
