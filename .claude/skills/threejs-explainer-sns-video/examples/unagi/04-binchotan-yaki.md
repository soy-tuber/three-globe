# 04 炭火で焼くと、なぜ皮はパリッと中はふっくらするのか

- 用途：飲食の現場の採用（焼き手の仕事の魅力）と、焼き場の新人教育
- 見る人：応募を考えている人、新人の焼き手、ホールスタッフ
- 状態：サンプル。「もっと知る」の事実は出典を確認してから確定する（要確認）

---

炭火の焼き台で、熱がどう鰻に届き、皮と身がどう変わっていくのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
炭火の熱は、主に炎ではなく、赤く焼けた炭から出る目に見えない赤外線（熱放射）として鰻に届く。
その強さは炭との距離で大きく変わる。だから焼き手は串の高さを細かく変えて、表面だけを一気に焼き固め、中はゆっくり火を通している。
これを、光る熱放射と「串の高さを変える」という操作1つで体感させる。
最初の2秒で「焼き台の炭」「串に打った鰻」「炭から立ち昇る光る熱」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：焼き台に赤く光る炭が並び、上に竹串を打った開いた鰻が置かれている。炭から熱放射の光の筋が上へ放たれ、鰻の下面に当たっている
② 操作：串の高さ（炭の表面からの距離）を、串のドラッグで上下させる。ホイール、スライダー、↑↓キーでも同じ値が動く。串に触れたときだけ高さを操作し、それ以外のドラッグはカメラを回す
③ 変化：炭に近づけるほど、鰻の皮の面が琥珀に光り、表面温度のメーターが急に伸びる。断面の温度分布が、表面から中へじわじわ広がっていく
④ しきい値を越えた瞬間：皮の表面温度が焼き色のつく温度を越えると、皮に細かな泡が立ち、白い閃光とともに焼き色が広がる。そのあと約8倍のスローで焼きの工程を見せる
   ①乾かす 皮の表面の水分を飛ばす　②色づく 焼き色がつき香りが出る　③脂が落ちる 脂が炭に落ちて香りの煙が立つ　④返す 身の側を焼く　⑤タレ タレをくぐらせる　⑥仕上げ もう一度焼いて照りを出す
⑤ 成功：「ジュッ」という短い音。表示に「表面 焼き色　中 ふっくら」を出す
⑥ 失敗・中断：串を炭に近づけすぎたまま置くと、表面温度が焦げの温度を越えて皮が黒くなる。表示が赤で「焦げ　高さを上げてください」。落ちた脂から炎が上がる。カメラが少し引いて炎を見せ、数秒後に串を上げると収まる
⑦ 「分解」ボタン：焼き台（炭床／ロストル／焼き網の受け／灰受け）と、鰻の断面の層（皮／皮下の脂／身）が浮き上がる。鰻の断面は3倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。炭床は幅60×奥行30cm、開いた鰻は長さ30×幅8×厚さ1.2cm
- 熱放射：炭の表面を一様な温度の面とみなし、ステファン・ボルツマンの法則 q = εσT⁴ に、平行な長方形どうしの形態係数 F(h) を掛けて、鰻の下面が受ける熱の量を求める。形態係数は厳密式か、面を細かく分けた数値積分で求める
- 放射の筋は、炭の各点から出る光線を束にして描く。明るさは受ける熱の量に対して単調にし、弱いところも読める程度に圧縮する
- 身の中の温度：厚さ方向の1次元の熱伝導を陽解法で解く（模型の熱伝導率、比熱、密度）。表面の境界条件は、受ける熱放射から蒸発と対流の損失を引いたものにする
- 焼き色：表面温度が約150℃を越えたら焼き色の進み具合を積分して増やす（模型の値）。焦げは約220℃を越えた時間の積分で判定する（模型の値）
- 串の高さの目盛りの中ほどで焼き色のしきい値を越えるように模型の値を合わせ、表面温度は上限で頭打ちにする
- 脂の落下と炎：表面温度が高く、脂の落下量が多いときに小さな炎を出す（模式表示）
- NaN を出さない：高さ0での割り算、長さ0のベクトルの正規化、負の数の pow を避ける

# 見た目
- 舞台：開店直前の鰻店の焼き場。暗い室内で、炭の赤い光だけが焼き手の手元を照らしている。立ち昇る煙が光を受けて浮かび上がる
- 材質：黒い鉄の焼き台、白い灰をまとった炭、竹串、濡れたように光る鰻の皮
- 色の約束：
  - 熱放射は赤〜橙の光の筋（炭の色の延長として）
  - 鰻が受け取った熱は琥珀
  - 焼き色が成立する瞬間は白い閃光
  - 焦げと炎の危険は赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「炭火で焼くと、なぜ皮はパリッと中はふっくらするのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：炭火の熱は、炎ではなく、赤く焼けた炭から出る赤外線として鰻に届きます。焼き手は串の高さを変えて、その強さを操っています。串を動かして、焼き色がつく瞬間を見てください。
- メーター：皮の表面温度。線形。しきい値の破線に「焼き色がつき始めるライン」、その上に「焦げ始めるライン」を付ける
- 小さなグラフ：炭からの距離と、受ける熱の量の曲線。現在値の点と、焼き色のしきい値の縦線を入れる。注記「炭から離れるほど、届く熱は急に弱まります」を添える
- 処理タイムライン：スロー中は「経過 2分10秒」のような実時間カウンタを出し、仕上げの完了時に「1枚を焼き上げるまで、実際には十数分かかります」と出す（時間は模型の値）
- 小さなオシロスコープ：表面温度と中心温度の時間変化の2本の線
- 操作ボタン：お手本（焼き手の高さの動かし方を自動で再生）、分解、スロー／実時間、カメラ（全体／焼き台／鰻の断面／焼き手の目線）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や鰻の断面図の上には置かない
- 成功と失敗は、鰻のそばに大きな吹き出しでも出す
- 注記：温度と時間は原理を示すための模型の値です。身の中の温度の分布は模型による計算のイメージです。焼きの進み方は目で見える速さに変えた模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに高さ・表面温度・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実は下の候補のうち、出典を確認できたものだけを使う）
① 【要確認】炭火の加熱は、熱放射の割合が大きい（出典の候補：調理科学の教科書、日本調理科学会誌の論文）
② 【要確認】ステファン・ボルツマンの法則：物体が出す熱放射は絶対温度の4乗に比例する（出典の候補：伝熱工学の教科書）
③ 【要確認】焼き色と香ばしい香りは、アミノ酸と糖が高温で反応するメイラード反応などによる（出典の候補：食品化学の教科書、日本食品科学工学会の資料）
④ 【要確認】備長炭は硬く、火持ちがよく、煙や炎が少ないとされる（出典の候補：林野庁、日本特用林産振興会の資料）
⑤ 【要確認】鰻の職人の修業を表す「串打ち三年、割き八年、焼き一生」という言い回し（出典の候補：業界団体、専門店の公開情報）

# 検証用フックと録画モード
- window.__lab = { ready, setHeight(cm), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real') }
  - setHeight の直後の getState は、受ける熱の量・表面温度・焼き色・焦げの判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　焼き場の全体の絵「鰻を焼く炭火の熱は、炎ではありません」
  - 3〜7秒　炭へ寄る「赤く焼けた炭は、目に見えない赤外線で鰻を焼いています」
  - 7〜12秒　串がゆっくり下がる「炭に近づけるほど、届く熱は急に強くなります」
  - 12〜14秒　焼き色のしきい値を越える「皮の温度がある線を越えた瞬間、焼き色がつき始めます」
  - 14〜18.5秒　スローで焼きの工程「表面は一気に焼き固め、中はゆっくり火を通します」
  - 18.5〜23秒　焼き上がり「皮はパリッと、中はふっくら。焼き手は串の高さでこれを作ります」
  - 23〜27秒　近づけすぎる→焦げと炎「近すぎると、ほんの数秒で焦げてしまいます」
  - 27〜30秒　分解した引きの絵「だから焼きは、一生かけて磨く技だと言われます」
