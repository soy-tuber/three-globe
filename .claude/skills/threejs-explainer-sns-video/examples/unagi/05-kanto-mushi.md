# 05 なぜ関東の鰻は蒸すのか

- 用途：飲食の現場の新人教育（最初の1本）と採用
- 見る人：新人の厨房スタッフ、ホールスタッフ、応募を考えている人
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）

---

関東風の鰻の「蒸し」の工程で、蒸気の熱がどう身に伝わり、身がどう変わるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
蒸気は、鰻の冷たい表面に触れた瞬間に水へ戻り、そのとき大きな熱を一気に手渡す。だから蒸し器の中は100℃前後なのに、同じ温度のオーブンよりずっと速く身に火が通る。
身の中では、身がやわらかくなり、余分な脂が落ちていく。
これを、光る蒸気と「蒸す時間を延ばす」という操作1つで体感させる。
最初の2秒で「蒸し器」「白焼きの鰻」「立ちこめる光る蒸気」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：湯気の立つ蒸籠の中に、串を打って素焼きにした白焼きが並んでいる。蒸籠の中を、見えない蒸気の流れが青白い粒で示されている
② 操作：蒸す時間を、蒸籠のふたのドラッグ（開け閉めの回数ではなく、時間の目盛りを回す）で進める。ホイール、スライダー、↑↓キーでも同じ値が動く。ふたに触れたときだけ時間を操作し、それ以外のドラッグはカメラを回す
③ 変化：蒸気の粒が身の表面で水滴に変わるたびに、表面が琥珀に光る。断面の温度分布が中へ広がり、中心温度のメーターが伸びていく
④ しきい値を越えた瞬間：中心温度が身がやわらかくなる温度帯に入ると、断面の筋の組織がほどけるように広がり、白い閃光。そのあと約20倍のスローで、身の中の変化を見せる
   ①触れる 蒸気が冷たい表面に触れる　②水に戻る 水に戻るときに熱を渡す　③伝わる 熱が身の中へ広がる　④ほぐれる 身がやわらかくなる　⑤落ちる 余分な脂が落ちる　⑥やわらかく 脂肪が多少除かれ、肉が軟らかくなる
⑤ 成功：「ポン」という短い音。表示に「中心まで均一　やわらかく」を出す
⑥ 失敗・中断：蒸す時間を延ばしすぎると、鰻のエッセンスが出切ってしまう。表示が赤で「蒸しすぎ　鰻のエッセンスが出切ります」。カメラが少し引いて身を箸で持ち上げる場面を見せ（身の変化は模型のイメージと明記する）、数秒後に時間を戻すと元に戻る
⑦ 「分解」ボタン：蒸籠（ふた／簀の子／枠／湯を張った鍋）と、鰻の断面の層（皮／皮下の脂／身の筋の束）が浮き上がる。身の筋の束は3倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。白焼きは長さ20×幅8×厚さ1.2cm。蒸籠の中の温度は約100℃
- 蒸気の凝縮：蒸気が表面温度の低い身に触れると凝縮し、1kg あたり約2,257kJ の潜熱を渡す。凝縮の熱伝達率は、同じ温度の乾いた空気の対流よりずっと大きい値（模型の値）にする
- 身の中の温度：厚さ方向の1次元の熱伝導を陽解法で解く（模型の熱伝導率、比熱、密度）。表面の境界条件は凝縮による熱の受け取りとする
- 比較用に「同じ100℃の乾いた空気（オーブン）」の場合も同じ式で計算し、グラフに薄い線で重ねる。乾いた空気では、湿った食品の表面は水分の蒸発に熱が使われて100℃に届かないように、蒸発で冷える分を入れる
- やわらかさ：中心温度が模型の温度帯（例：65〜80℃）に入っている時間を積分して「ほぐれ度」とする。脂の減り方と身の崩れも時間の積分で判定する（模型の値）
- 時間の目盛りの中ほどで中心温度がしきい値を越えるよう模型の値を合わせ、ほぐれ度は上限で頭打ちにする
- NaN を出さない：長さ0のベクトルの正規化、負の数の pow、ゼロ除算を避ける

# 見た目
- 舞台：仕込みの時間の鰻店の厨房。窓からの朝の光、蒸籠から立ち昇る湯気が光を受けて白く浮かぶ
- 材質：使い込んだ檜の蒸籠、白い陶器、ステンレスの鍋
- 色の約束：
  - 蒸気は青白の粒
  - 鰻が受け取った熱は琥珀
  - 身がやわらかくなる瞬間は白い閃光
  - 蒸しすぎのエラーは赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「なぜ関東の鰻は蒸すのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：関東の鰻は、たれをつけて焼く前に一度蒸します。蒸気は身に触れた瞬間に水に戻り、大きな熱を一気に手渡します。蒸す時間を進めて、身がやわらかく変わる瞬間を見てください。
- メーター：中心温度。線形。しきい値の破線に「身がやわらかくなり始めるライン」と付ける
- 小さなグラフ：時間と中心温度の曲線。蒸気の場合と、同じ温度の乾いた空気の場合の2本を重ね、現在値の点を入れる。注記「同じ100℃でも、蒸気のほうがずっと速く熱を伝えます」を添える
- 処理タイムライン：スロー中は「経過 4分30秒」のような実時間カウンタを出し、完了時に「蒸しの工程は、実際には20〜30分位です（それ以上かかることもあります）」と出す
- 小さなオシロスコープ：表面温度と中心温度の時間変化
- 操作ボタン：お手本（適切な時間まで自動で蒸す）、分解、スロー／実時間、関東風と関西風の切り替え、カメラ（全体／蒸籠の中／身の断面／箸で持ち上げる）
- 関東風と関西風の切り替えは、食感の言葉ではなく工程の違いで示す（関東風：背開き→白焼き→蒸す→たれをつけて焼く／関西風：腹開き→蒸さずにたれをつけて焼く）。関西風では蒸しの工程がないことが分かるようにする
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や身の断面図の上には置かない
- 成功と失敗は、蒸籠のそばに大きな吹き出しでも出す
- 注記：温度と時間は原理を示すための模型の値です。身の中の変化は模型による計算のイメージです。蒸気の動きは目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに時間・中心温度・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの5つだけを使う）

水産増殖 39巻2号（1991）の2本は著者の所属に実在の鰻店・事業者の名前があるので、パネルでは雑誌名と題名だけを出し、所属は出さない。

① 関東では、鰻を背開きにして骨と内臓を取り、串に刺して白焼きにし、蒸します。そして、炭火でたれをつけながら焼きあげます。関西では、腹開きにして骨と内臓を取り、串に刺し、蒸さずに炭火でたれをつけながら焼きあげます。（農林水産省「うちの郷土料理」「鰻のかば焼き 東京都」 https://www.maff.go.jp/j/keikaku/syokubunka/k_ryouri/search_menu/menu/34_24_tokyo.html ）白焼きを蒸すと、脂肪が多少除かれ、肉が軟らかくなります。（調理科学 12巻2号（1979）「ウナギ」 https://www.jstage.jst.go.jp/article/cookeryscience1968/12/2/12_85/_article/-char/ja/ ）蒸し器では20〜30分位蒸すが、それ以上かかるときもあり、蒸し過ぎると鰻のエッセンスが出切ってしまうので、その一歩手前で止める、という説明があります。（水産増殖 39巻2号（1991）「4.関東(江戸)風蒲焼き考—特に調理方法について」 https://www.jstage.jst.go.jp/article/aquaculturesci1953/39/2/39_2_228/_article/-char/ja/ ）
② 関東で背開きになったのは、江戸時代中期、武士文化であった関東で、腹を開くのは切腹を連想させ縁起が悪いと嫌われたから、と言われています。（農林水産省 広報誌 aff 2016年7月号「特集2 鰻(1)」 https://www.maff.go.jp/j/pr/aff/1607/spe2_01.html ）一方で、腹はやわらかくて裂くのが難しく、背は硬くて包丁を入れやすいことから、包丁さばきは関西のほうが上だった、とみる見方もあります。（水産増殖 39巻2号（1991）「5.関西鰻蒲焼論」 https://www.jstage.jst.go.jp/article/aquaculturesci1953/39/2/39_2_229/_article/-char/ja/ ）
③ 水の蒸発（凝縮）潜熱は、1kg あたり約2257 kJ です。食品の温度が低いうちは、表面で水蒸気が凝縮（結露）します。これを利用すると、水分の蒸発を抑えながら急速に加熱できます。100℃の空気を湿った食品に吹き付けても、熱が水分の蒸発に使われるため100℃には届きませんが、飽和水蒸気を使うと、表面温度を100℃まで急速に上げられます。飽和水蒸気を使う加熱は、蒸し加熱に近いものです。（日本食品工学会誌 25巻1号（2024）「食品加工における過熱水蒸気利用に関する研究」 https://www.jstage.jst.go.jp/article/jsfe/25/1/25_23641/_article/-char/ja/ ）
④ 水蒸気を使うオーブン加熱について、水を含ませたガーゼ球を試料にして、加わる熱を対流、ふく射、伝導伝熱および凝縮伝熱に分けて解析した研究があります。水蒸気の凝縮を伴うオーブン加熱では、加熱初期に食品表面での水蒸気の凝縮熱によって急速に熱が与えられ、その後は水分の蒸発を伴いながら、対流やふく射（放射）で加熱されると説明されています。（日本食品科学工学会誌 59巻10号（2012）「水蒸気凝縮を伴う調理オーブンの伝熱機構解析」 https://www.jstage.jst.go.jp/article/nskkk/59/10/59_491/_article/-char/ja/ ）
⑤ 魚の皮や骨のコラーゲンは、50〜60℃位に加熱すると収縮し、そのまま熱し続けると分解してゼラチンになります。煮魚のまわりにできる煮こごりは、このゼラチンです。なお、魚肉の筋組織が畜肉より軟らかいのは、結合組織のたんぱく質（肉基質たんぱく質）が2〜5％で、畜肉の20〜30％よりはるかに少ないためと考えられています。（生活衛生 27巻4号（1983）「魚の調理」 https://www.jstage.jst.go.jp/article/seikatsueisei1957/27/4/27_4_221/_article/-char/ja/ ）

# 検証用フックと録画モード
- window.__lab = { ready, setSteamTime(分), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setStyle('kanto'|'kansai') }
  - setSteamTime の直後の getState は、中心温度・ほぐれ度・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　蒸籠と白焼きの全体の絵「関東の鰻は、たれをつけて焼く前に一度蒸します」
  - 3〜7秒　蒸籠の中へ寄る「蒸籠の中には、目に見えない蒸気が満ちています」
  - 7〜12秒　蒸す時間が進む「蒸気は身に触れた瞬間に水に戻り、大きな熱を渡します」
  - 12〜14秒　中心温度がしきい値を越える「中まで熱が届いた瞬間、身がやわらかくほどけ始めます」
  - 14〜18.5秒　スローで身の中の変化「身がやわらかくなり、余分な脂が落ちていきます」
  - 18.5〜23秒　蒸し上がりと関西風との比較「関東は白焼きを蒸してから焼き、関西は蒸さずに焼きます。どちらも地域の文化です」
  - 23〜27秒　蒸しすぎ→エッセンスが出切る「蒸しすぎると、鰻のエッセンスが出切ってしまいます」
  - 27〜30秒　分解した引きの絵「だから蒸しの時間は、毎日の鰻の様子を見て決めます」
