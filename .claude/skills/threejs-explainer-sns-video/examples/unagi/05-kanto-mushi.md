# 05 なぜ関東の鰻は蒸すのか

- 用途：飲食の現場の新人教育（最初の1本）と採用
- 見る人：新人の厨房スタッフ、ホールスタッフ、応募を考えている人
- 状態：サンプル。「もっと知る」は検索で出典を記入済み。公開前に各リンク先の本文を確認する

---

関東風の鰻の「蒸し」の工程で、蒸気の熱がどう身に伝わり、身がどう変わるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
蒸気は、鰻の冷たい表面に触れた瞬間に水へ戻り、そのとき大きな熱を一気に手渡す。だから蒸し器の中は100℃前後なのに、同じ温度のオーブンよりずっと速く身に火が通る。
身の中では、かたい筋の組織がほぐれてやわらかくなり、余分な脂が落ちていく。
これを、光る蒸気と「蒸す時間を延ばす」という操作1つで体感させる。
最初の2秒で「蒸し器」「白焼きの鰻」「立ちこめる光る蒸気」が一目で分かる絵にすること。

# 体験の流れ
① 初期状態：湯気の立つ蒸籠の中に、串を打って素焼きにした白焼きが並んでいる。蒸籠の中を、見えない蒸気の流れが青白い粒で示されている
② 操作：蒸す時間を、蒸籠のふたのドラッグ（開け閉めの回数ではなく、時間の目盛りを回す）で進める。ホイール、スライダー、↑↓キーでも同じ値が動く。ふたに触れたときだけ時間を操作し、それ以外のドラッグはカメラを回す
③ 変化：蒸気の粒が身の表面で水滴に変わるたびに、表面が琥珀に光る。断面の温度分布が中へ広がり、中心温度のメーターが伸びていく
④ しきい値を越えた瞬間：中心温度が身がやわらかくなる温度帯に入ると、断面の筋の組織がほどけるように広がり、白い閃光。そのあと約20倍のスローで、身の中の変化を見せる
   ①触れる 蒸気が冷たい表面に触れる　②水に戻る 水に戻るときに熱を渡す　③伝わる 熱が身の中へ広がる　④ほぐれる かたい筋がやわらかくなる　⑤落ちる 余分な脂が落ちる　⑥ふっくら 身が水分を含んで膨らむ
⑤ 成功：「ポン」という短い音。表示に「中心まで均一　ふっくら」を出す
⑥ 失敗・中断：蒸す時間を延ばしすぎると、身が崩れ、脂が抜けすぎてパサつく。表示が赤で「蒸しすぎ　身が崩れます」。カメラが少し引いて崩れた身を箸で持ち上げる場面を見せ、数秒後に時間を戻すと元に戻る
⑦ 「分解」ボタン：蒸籠（ふた／簀の子／枠／湯を張った鍋）と、鰻の断面の層（皮／皮下の脂／身の筋の束）が浮き上がる。身の筋の束は3倍に拡大し、そう明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。白焼きは長さ20×幅8×厚さ1.2cm。蒸籠の中の温度は約100℃
- 蒸気の凝縮：蒸気が表面温度の低い身に触れると凝縮し、1kg あたり約2,257kJ の潜熱を渡す。凝縮の熱伝達率は、同じ温度の乾いた空気の対流よりずっと大きい値（模型の値）にする
- 身の中の温度：厚さ方向の1次元の熱伝導を陽解法で解く（模型の熱伝導率、比熱、密度）。表面の境界条件は凝縮による熱の受け取りとする
- 比較用に「同じ100℃の乾いた空気（オーブン）」の場合も同じ式で計算し、グラフに薄い線で重ねる
- やわらかさ：中心温度が模型の温度帯（例：65〜80℃）に入っている時間を積分して「ほぐれ度」とする。脂の減り方と身の崩れも時間の積分で判定する（模型の値）
- 時間の目盛りの中ほどで中心温度がしきい値を越えるよう模型の値を合わせ、ほぐれ度は上限で頭打ちにする
- NaN を出さない：長さ0のベクトルの正規化、負の数の pow、ゼロ除算を避ける

# 見た目
- 舞台：仕込みの時間の鰻店の厨房。窓からの朝の光、蒸籠から立ち昇る湯気が光を受けて白く浮かぶ
- 材質：使い込んだ檜の蒸籠、白い陶器、ステンレスの鍋
- 色の約束：
  - 蒸気は青白の粒
  - 鰻が受け取った熱は琥珀
  - 身がやわらかくなる瞬間は白い閃光
  - 蒸しすぎのエラーは赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「なぜ関東の鰻は蒸すのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：関東の鰻は、焼く前に一度蒸します。蒸気は身に触れた瞬間に水に戻り、大きな熱を一気に手渡します。蒸す時間を進めて、身がふっくら変わる瞬間を見てください。
- メーター：中心温度。線形。しきい値の破線に「身がやわらかくなり始めるライン」と付ける
- 小さなグラフ：時間と中心温度の曲線。蒸気の場合と、同じ温度の乾いた空気の場合の2本を重ね、現在値の点を入れる。注記「同じ100℃でも、蒸気のほうがずっと速く熱を伝えます」を添える
- 処理タイムライン：スロー中は「経過 4分30秒」のような実時間カウンタを出し、完了時に「蒸しの工程は、実際には十数分から数十分です」と出す（時間は模型の値。出典で確認して調整する）
- 小さなオシロスコープ：表面温度と中心温度の時間変化
- 操作ボタン：お手本（適切な時間まで自動で蒸す）、分解、スロー／実時間、関東風と関西風の切り替え、カメラ（全体／蒸籠の中／身の断面／箸で持ち上げる）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や身の断面図の上には置かない
- 成功と失敗は、蒸籠のそばに大きな吹き出しでも出す
- 注記：温度と時間は原理を示すための模型の値です。身の中の変化は模型による計算のイメージです。蒸気の動きは目で見える速さに落とした模式表示です。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに時間・中心温度・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの5つだけを使う）
※ 2026年9月の検索で見つけた資料をもとに記入した。作業環境のネットワーク制限で原文のページを開けず、検索結果の要約で内容を確かめている。公開前に、各リンク先の本文で文言と数値を確認すること。【注意】の付いた項目は、資料によって内容が異なるか、一次資料ではないもの。

① 関東風は背開きにして白焼きを蒸してから焼き、ふっくらやわらかく仕上げます。関西風は腹開きで蒸さずに焼き、表面をパリッと香ばしく仕上げます。（浜名湖産直マーケット「関東と関西で異なるうなぎの蒲焼」 https://www.8075.jp/blog/topics/873/ ）【注意】専門店の解説。公的な資料があれば差し替える
② 関東で背開きになったのは、武士の多い江戸で腹開きが切腹を連想させて嫌われたから、という説があります。（大五うなぎ工房「関東の背開き、関西の腹開き」 https://www.unagi-koubou.jp/contents/unagi_trivia/2134.html ）【注意】俗説として紹介する
③ 水蒸気が水に戻るときには、1kg あたり約2,257kJ の熱（潜熱）を放出します。蒸し加熱が速いのは、この熱が食材の表面で一気に渡されるためです。（コメットカトウ「スチームコンベクションオーブンの蒸気加熱の利点とは？」 https://www.cometkato.co.jp/column/benefits-of-steamheating-01/ ）【注意】潜熱の値は理科年表などで確認する
④ 水蒸気を使ったオーブン加熱の伝わり方は、対流、放射、伝導、凝縮に分けて研究されています。（日本食品科学工学会誌「水蒸気凝縮を伴う調理オーブンの伝熱機構解析」 https://www.jstage.jst.go.jp/article/nskkk/59/10/59_491/_article/-char/ja/ ）
⑤ 魚の皮や筋に多いコラーゲンは、水分とともに長く加熱するとほぐれてゼラチンに変わり、身がやわらかくなります。（宝酒造「魚、肉の食感」 https://chomiryo.takarashuzo.co.jp/knowledge/detail/105/ ）

# 検証用フックと録画モード
- window.__lab = { ready, setSteamTime(分), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('slow'|'real'), setStyle('kanto'|'kansai') }
  - setSteamTime の直後の getState は、中心温度・ほぐれ度・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　蒸籠と白焼きの全体の絵「関東の鰻は、焼く前に一度蒸します」
  - 3〜7秒　蒸籠の中へ寄る「蒸籠の中には、目に見えない蒸気が満ちています」
  - 7〜12秒　蒸す時間が進む「蒸気は身に触れた瞬間に水に戻り、大きな熱を渡します」
  - 12〜14秒　中心温度がしきい値を越える「中まで熱が届いた瞬間、身がやわらかくほどけ始めます」
  - 14〜18.5秒　スローで身の中の変化「かたい筋がほぐれ、余分な脂が落ちていきます」
  - 18.5〜23秒　蒸し上がりと関西風との比較「関東はふっくら、関西はパリッと香ばしく。どちらも地域の文化です」
  - 23〜27秒　蒸しすぎ→身が崩れる「蒸しすぎると、身は崩れてしまいます」
  - 27〜30秒　分解した引きの絵「だから蒸しの時間は、毎日の鰻の様子を見て決めます」
