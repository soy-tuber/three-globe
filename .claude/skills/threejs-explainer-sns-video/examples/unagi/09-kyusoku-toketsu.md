# 09 急速凍結すると、なぜ解凍してもおいしいのか

- 用途：加工現場（冷凍蒲焼きの製造）の教育と、設備投資の説明
- 見る人：加工場のスタッフ、品質管理の担当者、経営者、取引先
- 状態：サンプル。「もっと知る」は2026年9月29日に各リンク先の本文で文言と数値を確認し、原文に合わせて直した（FACT-CHECK.md）

---

鰻の蒲焼きを凍らせるときに、身の中で氷の結晶がどう育ち、冷やす速さで何が変わるのかを見せる、インタラクティブな3D解説ページを HTML 1枚で作ってください。
目的は、日本の SNS に30秒の画面録画を投稿して、多くの人に見てもらうことです。

# 見せたいこと
身の水分が凍るとき、氷の結晶は特定の温度帯で大きく育ちやすい。その温度帯をゆっくり通ると、結晶が大きく育って細胞を押し広げ、解凍したときに旨味を含んだ水分（ドリップ）が流れ出す。
急速に冷やしてその温度帯を素早く通り抜けると、結晶は小さいままで、解凍しても身がふっくらしたまま残る。
これを、光る氷の結晶と「冷やす速さを上げる」という操作1つで体感させる。
最初の2秒で「真空包装した蒲焼き」「冷凍庫」「身の中で育つ光る氷の結晶」が一目で分かる絵にすること。

# 技術の条件
- index.html 1枚。three.js は importmap で https://cdn.jsdelivr.net/npm/three@0.183.2/ から読む

# 体験の流れ
① 初期状態：真空包装した蒲焼きが冷凍庫の棚に置かれ、身の一部が拡大されて、細胞の並びが半透明で見えている。冷気が青白い流れとして包装のまわりを通っている
② 操作：冷やす速さ（冷凍庫の温度と風の強さをまとめた1つの目盛り）を、冷凍庫の扉の横のつまみのドラッグで変える。ホイール、スライダー、↑↓キーでも同じ値が動く。つまみに触れたときだけ速さを操作し、それ以外のドラッグはカメラを回す
③ 変化：冷やす速さを上げるほど冷気の流れが太く明るくなり、中心温度のグラフの下がり方が急になる。温度帯を通り抜けるのにかかる時間のメーターが短くなる
④ しきい値を越えた瞬間：通り抜ける時間が一定より短くなると、細胞の中にも外にも小さな結晶が一斉にできて、白い閃光。そのあと、凍結から解凍までを約300倍の早回しで見せる
   ①冷える 身の温度が下がる　②凍り始める 水分が凍り始める　③通り抜ける 結晶が育ちやすい温度帯を通る　④固まる 全体が凍る　⑤保存 冷凍保存する　⑥解凍 溶かしたときに水分が身に残るかを見る
⑤ 成功：「カチッ」という短い音。表示に「結晶 小さいまま　ドリップ わずか」を出す
⑥ 失敗・中断：冷やす速さを落とすボタンを押すと、温度帯をゆっくり通り、結晶が大きく育って細胞を押しつぶす。解凍するとドリップが流れ出す。表示が赤で「結晶が大きく育ちました」。カメラが少し引いて皿に広がるドリップを見せ、数秒後に元に戻る
⑦ 「分解」ボタン：製品の層（真空包装のフィルム／タレ／蒲焼きの身／皮）と、凍結設備（冷却器／送風機／棚／温度センサー）が浮き上がる。身の細胞は大きく拡大し、「模式図」と明記する

# 物理（原理は正しく、数値は模型の値）
- 単位：1 = 1cm。蒲焼きは長さ18×幅8×厚さ1.5cm。包装を含めて1枚の板として扱う
- 温度：厚さ方向の1次元の熱伝導を、凍るときの潜熱を含むエンタルピー法で解く。凍り始める温度（模型の値、0℃より少し低い）から下では、潜熱の放出で温度の下がり方が鈍る
- 表面の境界条件：冷気の温度と、風の強さで決まる熱伝達率（模型の値）で表す。1つの目盛りで両方を動かす
- 結晶の大きさ：結晶が育ちやすい温度帯（最大氷結晶生成温度帯、通常 −1〜−5℃。食品によって異なるので模型の値とする）に各層がとどまった時間を積分し、それに応じて結晶の大きさを決める
- ドリップ：結晶の大きさが細胞の大きさを越えた割合から、解凍時に流れ出す水分の量を求める（模型の値）
- 冷やす速さの目盛りの中ほどで、通り抜ける時間がしきい値を下回るように模型の値を合わせる。結晶の大きさとドリップは上限で頭打ちにする
- NaN を出さない：ゼロ除算、負の数の pow、長さ0のベクトルの正規化を避ける

# 見た目
- 舞台：加工場の凍結室。青みを帯びた冷たい照明、ステンレスの棚、白く霜のついた壁、吐く息が白くなりそうな空気
- 材質：ステンレスの棚、透明な真空包装、照りのある蒲焼き
- 色の約束：
  - 冷気は青白の流れ
  - 身の中の熱（まだ凍っていない部分）は琥珀
  - 小さな結晶が一斉にできる瞬間は白い閃光
  - 大きく育った結晶とドリップの警告は赤
- UI は白〜グレーの細線にし、金色の装飾は使わない
- ブルームは解像度を落として控えめに使う

# 画面
- 見出し「急速凍結すると、なぜ解凍してもおいしいのか」を、最初の3秒だけ上中央に大きく出し、その後は小さく畳む
- リード：身の水分は、凍るときに氷の結晶になります。ゆっくり凍らせると結晶が大きく育ち、身を傷めてしまいます。冷やす速さを変えて、結晶の育ち方を見てください。
- メーター：結晶が育ちやすい温度帯を通り抜けるのにかかった時間。線形。しきい値の破線に「結晶が小さいまま凍るライン」と付ける
- 小さなグラフ：時間と中心温度の曲線。結晶が育ちやすい温度帯を帯で示し、現在値の点を入れる。注記「この温度帯を早く通り抜けるほど、結晶は小さいままです」を添える
- 処理タイムライン：早回し中は「経過 35分」のような実時間カウンタを出し、完了時に「実際の凍結にかかる時間は、設備や製品によって異なります」と出す
- 小さなオシロスコープ：表面温度と中心温度の変化の2本の線
- 操作ボタン：急速凍結（自動で適切に凍らせる）、分解、早回し／実時間、緩慢凍結、解凍、カメラ（全体／身の中／細胞／皿の上）
- 部品ラベルは引き出し線つき。重なったら優先度の低いほうを隠し、UI や細胞の拡大図の上には置かない
- 成功と失敗は、冷凍庫のそばに大きな吹き出しでも出す
- 注記：温度と時間は原理を示すための模型の値です。身の細胞と結晶の様子は模式図で、大きさは実際と異なります。凍結設備の内部は公開情報をもとにしたイメージです。
- Canvas に描く文字は、document.fonts.load で書体を読み込んでから描く
- スマホ幅（390px）：上に見出しとボタン、下のシートに冷やす速さ・通り抜ける時間・①〜⑥・操作をまとめ、グラフとオシロは「開く」で出す

# もっと知る（出典リンクつきの開閉パネル。事実はこの4つだけを使う）
※ 2026年9月29日に、各リンク先の本文で文言と数値を確認した（FACT-CHECK.md）。

① 食品の水分は、食品によって異なりますが、一般に−1℃あたりから凍り始め、−5℃程度でほぼ凍結します。この温度帯を「最大氷結晶生成温度帯」といいます。（日本冷凍食品協会 冷食オンライン「冷凍の世界 ～製品編～ 前編」 https://online.reishokukyo.or.jp/learn/basic/about/frozen-product_01/ ）
② この温度帯を通過する時間が長いと、氷の結晶どうしがくっつき合って大きく育ち、食品の組織を壊してしまいます。この温度帯を急速に通過させて、組織の損傷をできるだけ少なくする凍結方法を「急速凍結」といいます。急速凍結すると氷の結晶が小さいままなので、組織を圧迫せず、壊れにくくなります。日本冷凍食品協会の認定基準では、製品を凍結するときに、製品の中心温度がこの温度帯を概ね30分以内に通過することとしています。（日本冷凍食品協会 冷食オンライン「冷凍の世界 ～製品編～ 前編」 https://online.reishokukyo.or.jp/learn/basic/about/frozen-product_01/ 、日本冷凍食品協会「冷凍食品製造工場認定基準」令和7年度版 https://www.reishokukyo.or.jp/wp-content/uploads/2025/03/R%EF%BC%97-ninteiseido-p2-ninteikijunn.pdf ）
③ 日本冷凍食品協会は、冷凍食品の条件として「前処理している」「急速凍結している」「適切に包装している」「−18℃以下で保管している」の4つを挙げています。4つ目は、食品の温度（品温）を、生産・貯蔵・輸送・配送・販売の各段階を通じて、一貫して常に−18℃以下に保つように管理することです。（日本冷凍食品協会 冷食オンライン「冷凍食品とは」 https://online.reishokukyo.or.jp/learn/basic/about/ ）
④ 食肉をゆっくり凍らせると、氷の結晶の体積が増えて細胞組織が傷つき、解凍すると、細胞内の可溶成分（たんぱく質、エキス分、ビタミン類など）までが水分とともに細胞の外へ流れ出るため、うま味が低下します。凍った肉を解凍したときに、肉の内部から分離して出る液体を、一般にドリップといいます。（日本食肉消費総合センター「用語集：ドリップ」 https://www.jmi.or.jp/info/word/ta/ta_140.html ）食品一般でも、凍結に時間がかかると氷の結晶が成長して食品の組織を圧迫・破損し、食感の低下や、解凍後にドリップが流れ出るなどの品質の劣化が起きるとされています。（日本冷凍食品協会「冷凍食品製造事業者向けＨＡＣＣＰに基づく衛生管理のための手引書」第2版、厚生労働省ウェブサイト掲載 https://www.mhlw.go.jp/content/11130500/000808133.pdf ）

# 検証用フックと録画モード
- window.__lab = { ready, setCoolingRate(割合0〜1), getState(), tap(), setExploded(on), setCamera(name, instant), setSpeed('fast'|'real'), thaw() }
  - setCoolingRate の直後の getState は、通り抜ける時間・結晶の大きさ・ドリップの量・成功・失敗の判定まで反映済みの値を同期で返す
- ?demo=1 で30秒の自動再生にする。__lab.renderDemoFrame(t) で、時刻 t の状態を1フレーム同期で描けるようにする（動画の書き出し用）
- 台本と字幕（画面下中央に大きく、背景の帯つき）：
  - 0〜3秒　凍結室と蒲焼きの全体の絵「冷凍の蒲焼きは、凍らせ方で味が変わります」
  - 3〜7秒　身の中へ寄る「身の水分は、凍るときに氷の結晶になります」
  - 7〜12秒　冷やす速さがゆっくり上がる「結晶には、大きく育ちやすい温度帯があります」
  - 12〜14秒　しきい値を越える「その温度帯を素早く通り抜けた瞬間、結晶は小さいまま凍ります」
  - 14〜18.5秒　早回しで凍結から保存「小さな結晶は、細胞を押しつぶしません」
  - 18.5〜23秒　解凍して身がふっくら「だから解凍しても、旨味を含んだ水分が身に残ります」
  - 23〜27秒　ゆっくり凍らせる→ドリップが流れ出す「ゆっくり凍らせると結晶が育ち、旨味が流れ出してしまいます」
  - 27〜30秒　分解した引きの絵「だから加工場では、凍らせる速さまで管理しています」
